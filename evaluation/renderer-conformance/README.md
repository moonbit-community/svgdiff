# Renderer Conformance Comparison

Status: measurement baseline

Last verified: 2026-07-15

Conformance profile: `svgdiff-renderer-conformance-profile/24`

This evaluation compares raw `mizchi/svg@0.2.1` with the deterministic Chromium oracle. Its report shape remains `svgdiff-renderer-conformance/1`, independently from the conformance claim identified by `svgdiff-renderer-conformance-profile/24` in the production Comparison Profile. Engine regressions separately prove the project-owned style-precedence, ordinary-inheritance, CSS-computed-value, CSS Color 3/opacity, length used-value, stroke used-geometry, basic-shape used-geometry, rectangular clip semantics/bounds, isolated group/mask compositors, and static filter-graph compositor because this adapter deliberately isolates the underlying dependency.

Fixtures are classified as geometry, paint, alpha, clipping, or compositing; geometry includes basic shapes, strokes, markers, transforms, viewport mappings, authored units, and use instances, while paint includes cascade precedence, inheritance, computed CSS values, deterministic solid colors, gradients, patterns, embedded rasters, URL fallback selection, paint order, structural stacking, winding rules, and filter offsets. `supported` means the fixture exercises the current complete-eligible contract and `guarded` identifies a measured input that has a production Diagnostic. Six authored-unit fixtures cover absolute, percentage, viewport-relative, nested-viewport, stroke, and marker lengths; four canonical companions prove the browser equivalence of the first four. Eight cascade fixtures cover presentation-versus-inline origin, inline `!important`, stylesheet specificity, and stylesheet source order; all four authored cases have canonical companions. Inherited-stylesheet, CSS-wide fill, custom-property/`currentColor`, HSL, multiplied color/paint alpha, inherited paint opacity, clamped opacity, missing-server fallback color, missing-server no-paint, inherited paint order, inherited fill rule, and inherited clip rule inputs have canonical companions. Six focused gradient fixtures cover linear and radial geometry, object-bounding-box and user-space units, transforms, template inheritance, and multi-stop opacity. Six focused pattern fixtures cover object-bounding-box and user-space tiles, object-bounding-box content, viewBox mapping, transforms, and template inheritance. Six use fixtures cover repeated placement, host inheritance, symbol viewport mapping, nesting, and direct or nested transformed placement. Six admitted masks cover alpha, luminance, object-bounding-box coordinates, host mode override, transforms, and isolated container application; five are raw exact and the container divergence is owned by `static-mask-compositor@1`. Four admitted filter sources cover user-space offsets, object-bounding-box primitive units, named chains, and SourceAlpha; raw rendering diverges by 32 to 44 pixels, while four canonical companions are exact and the divergences are owned by `static-filter-graph-compositor@1`. Four admitted rectangle clips cover leaf, container, object-bounding-box, and deterministic transformed cases; two polygon clip-rule cases remain guarded. The 133-case baseline contains 61 exact and 72 divergent observations; all four admitted rectangle clips and all four filter canonical companions are exact, while the polygon cases retain `clip_path_content_unsupported`. The admitted PNG and JPEG fixtures each change 144 browser pixels while the pinned renderer leaves them absent, establishing `renderer_embedded_raster_unavailable`. Both structural stacking orders and four untransformed use fixtures are exact, while the two transform-plus-translation fixtures retain `renderer_use_transform_raster_unproven`. All four paint-fallback fixtures and both inherited fill-rule fixtures are exact. The inherited paint-order source diverges while its expanded leaf companion is exact. Both images are normalized to premultiplied RGBA8 before measuring changed pixels, changed-pixel fraction, RMSE, and maximum channel delta.

Run `sh scripts/test-renderer-conformance.sh` to capture Chromium output, render the same sources through the pinned renderer, and compare the deterministic result with `baseline.v1.json`. The baseline records the browser version, DPR, CLI version, and a fixture source-set hash without retaining platform-specific User-Agent text. A baseline divergence is an observation, not an acceptance decision. Every divergence must be handled by the following roadmap item before it may influence the coverage contract.

The MoonBit adapter under `evaluation/renderer_adapter` exports raw pinned-renderer RGBA pixels. The evaluation-local Python decoder intentionally supports only the 8-bit, non-interlaced RGB/RGBA PNG profile already enforced by the browser-oracle validator.

## Divergence dispositions

[`dispositions.v1.json`](dispositions.v1.json) maps every divergent baseline case to a production Diagnostic, reviewed normalizer, or reviewed product compositor. The baseline and disposition set both record `svgdiff-renderer-conformance-profile/24`; validation rejects a missing or mismatched identity. Absolute, percentage, viewport-relative, and nested-viewport unit divergences use canonical fixture pairs through `length-used-value-normalizer@1`; presentation/inline origin, inline-important, stylesheet-specificity, and stylesheet-source-order divergences use canonical pairs through `style-precedence-normalizer@3`; the inherited-stylesheet divergence uses `ordinary-inheritance-normalizer@1`; CSS-wide plus custom-property/`currentColor` divergences use `css-computed-value-normalizer@3`; HSL uses `css-color3-opacity-normalizer@1`; group opacity uses `isolated-group-compositor@1`, the container-mask divergence uses `static-mask-compositor@1`, and all four admitted filter-source divergences use `static-filter-graph-compositor@1`. Chromium renders every declared source/canonical pair identically. The validator requires complete computed equivalence and zero changed pixels when the canonical pinned-renderer case is exact, requires each compositor validation pair to emit one complete measured difference in its declared domain, and explicitly requires all four admitted clip fixtures, all six admitted mask fixtures, and all eight admitted filter/canonical fixtures to remain complete without their family guards. The polygon clip-rule fixtures use `clip_path_content_unsupported`; alpha pairs whose canonical pinned-renderer result still diverge retain `renderer_fractional_opacity_unproven`. Every focused gradient fixture diverges substantially and retains `renderer_gradient_raster_unproven`. Five pattern fixtures diverge and retain `renderer_pattern_raster_unproven`; the user-space fixture is exact but does not establish the other modes. PNG and JPEG remain explicitly unavailable for final rendering even though production decodes their intrinsic pixels. Other known fractional geometry, shape, stroke, marker, and transform divergences retain their dedicated guards.

Run `sh scripts/test-renderer-dispositions.sh` to require a one-to-one disposition for every divergence, execute each Diagnostic, normalizer, or compositor proof through the production CLI, and confirm that exact supported fixtures do not acquire a new conformance guard. Other analyzer limitations remain independent. A future versioned conformance profile may replace a guard with a reviewed tolerance or adapter fix.

The separate [alternate-scale QA baseline](../alternate-scale/README.md) measures pinned-renderer scale curves and directional behavior. It is not a browser conformance oracle and cannot change a disposition or canonical report magnitude by itself.
