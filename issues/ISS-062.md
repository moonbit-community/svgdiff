## Description
Make conservative Cause Envelope imprecision observable without weakening causal recall or collapsing report and Agent interpretation metrics.

## Design
Retain the existing actual-cause recall and unique false-positive counts. Add per-case report candidate counts, candidate occurrences across regions, region count, candidates per region, and false-positive fraction when actual-cause labels make precision scorable. Aggregate raw volume across every case, including partial comparison-wide fallbacks, while computing false-positive fractions only on eligible labeled cases.

## Acceptance Criteria
- [x] Per-case metrics expose unique report candidates, region occurrences, region count, and candidates per region even when ground-truth precision is not scorable.
- [x] Eligible cases expose false-positive count and fraction independently from Cause Envelope recall.
- [x] Aggregate metrics retain raw candidate and occurrence totals without a universal combined score.
- [x] Existing report and Agent causal recall and false-positive fields keep their meanings.
- [x] The deterministic baseline asserts exact current candidate-volume results.
- [x] Documentation explains why partial comparison fallbacks count toward volume but not false-positive precision without actual-cause labels.
