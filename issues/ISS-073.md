## Description
Define when one Changed Fact produces multiple visual outcomes and when several Changed Facts or Atomic Differences form one Visual Event, without losing difference inventory or duplicating report identity.

## Design
Give every Atomic Difference exactly one owning Visual Event. Anchor each current event to one primary Subject Alignment, group all differences for that outcome, and measure the rendered outcome once over its region union. Represent one-to-many causal fan-out by letting one Changed Fact be referenced by multiple Atomic Differences in multiple events; do not duplicate one Atomic Difference across events. Permit a resource difference to share the sole mediated entity event, but require a separate resource event when future resource fan-out would otherwise need an arbitrary owner. Keep cross-subject aggregation deferred.

## Acceptance Criteria
- [x] Domain terminology distinguishes authored change, reportable distinction, and outcome grouping.
- [x] Every Atomic Difference has exactly one owning Visual Event.
- [x] One Changed Fact can reach multiple Atomic Differences and events without duplication.
- [x] Multiple differences for one primary Subject Alignment form one event and one rendered outcome.
- [x] Resource-mediated zero-, one-, and multiple-outcome behavior is explicit.
- [x] Historical multi-event Atomic Difference guidance is superseded without erasing its rationale.
- [x] Current grouping invariants have executable regressions and Agent interpretation guidance.

## Close Notes
Defined `ChangedFact` as an authored possible cause, `AtomicDifference` as one independently reportable distinction, and `VisualEvent` as one primary aligned-subject outcome. Added ADR 0040: every Atomic Difference has exactly one event owner; causal fan-out crosses event boundaries through shared Changed Fact references. This partially supersedes ADR 0019's earlier allowance for one Atomic Difference to appear in several events while retaining its outcome-oriented rationale.

Specified that several differences and Changed Facts for one Primary Subject Alignment form one event and one rendered outcome over the region union. Separate primary alignments remain separate events. A resource difference may join its sole mediated entity event, an unreferenced resource uses a resource event, and future multi-entity resource fan-out must use a separate resource event until a versioned contextual-link or aggregation policy exists.
