## Description
Add cooperative cancellation and elapsed-time-budget handling for agents embedding the MoonBit library without changing ordinary comparison, CLI, or Structured Report semantics.

## Design
Follow ADR-0043. Add a public `ComparisonControl` containing a caller-owned cancellation predicate and optional maximum elapsed milliseconds, a typed `ComparisonInterrupted` error with distinct cancellation and time-budget cases, and `compare_with_control`. Keep `compare` as the unlimited backward-compatible operation.

Check cancellation before elapsed time at deterministic major-stage and measured hot-loop checkpoints. Use the same native clock as `moonbitlang/async` timers. Return no report on interruption; do not serialize truncated evidence or allocate new Diagnostics. Document that a dependency parse or render call is not preemptible and may overshoot the requested budget until the next checkpoint.

## Acceptance Criteria
- [x] Public callers can request cancellation and a wall-time budget independently or together.
- [x] Cancellation and time-budget expiry raise distinct typed errors and never return a partial or failed report.
- [x] Admission, alignment, per-event region work, report finishing, and serialization boundaries have cooperative checkpoints.
- [x] Unlimited and sufficiently budgeted controlled comparisons are byte-identical to `compare`.
- [x] Deterministic tests force immediate cancellation, cancellation from a later checkpoint, immediate expiry, and successful completion.
- [x] Existing CLI behavior and Structured Report Schema remain unchanged.
- [x] Library, status, resource, security, versioning, ADR, and roadmap documentation state the exact boundary.
