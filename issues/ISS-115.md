# ISS-115: Implement deterministic clipping and effect bounds

## Description
Implement static local SVG clipping for an admitted deterministic slice and replace the comparison-wide `clip_path_semantics_unsupported` guard with precise per-resource coverage. Produce exact or conservative effect bounds so a text-only Agent can localize both clip attachment changes and clip-resource geometry changes without confusing a bounding box with the actual clip mask.

## Design
Resolve non-inherited `clip-path` through the existing cascade, CSS-wide values, bounded custom-property substitution, and local-reference grammar. Admit `none` and local references to one static `clipPath` whose effective content is one non-rounded rectangle, with `clipPathUnits` equal to `userSpaceOnUse` or `objectBoundingBox` and transforms restricted to the already admitted deterministic axis-transform slice. Preserve the winning host declaration, resource attributes, child geometry facts, Source Spans, and consumer fan-out. Missing, external, wrong-kind, cyclic, multi-child, curved, dynamic, or otherwise unsupported clips remain source-visible behind precise Diagnostics.

Use the production renderer only for the admitted slice after exact Chromium conformance. Compute each affected host's clip effect bound by transforming the clip rectangle into viewport CSS space and intersecting it with the host's conservative painted bound. Keep before and after bounds separate internally and localize an event with their union; an empty intersection is a proven zero contribution. A conservative rectangle limits where clipping can matter but is not presented as the exact pixel mask. Clip-resource changes retain every affected consumer and their mediating host attachment; Cause Envelopes remain sound overapproximations.

## Acceptance Criteria
- [x] `clip-path` resolves through presentation attributes, inline style, stylesheets, CSS-wide values, and custom properties without becoming inherited.
- [x] `none`, local, missing, external, invalid, and wrong-kind clip locators have deterministic, source-located outcomes under the Resource Outcome Policy.
- [x] One static non-rounded rectangle clip supports `userSpaceOnUse` and `objectBoundingBox`, deterministic axis transforms, and leaf or container application.
- [x] Unsupported multi-child, curved/path, nested-reference, dynamic, or non-admitted transform semantics retain exact source facts and precise coverage Diagnostics rather than guessed pixels.
- [x] Host attachment changes and resource unit, transform, and rectangle-geometry changes produce typed Atomic Differences with source provenance, consumer fan-out, and deterministic same-domain ordering.
- [x] Each complete affected host has separate before/after conservative effect bounds; event localization uses their union and does not include unrelated scene regions.
- [x] Empty, fully covering, equivalent-spelling, insertion, deletion, movement, and resource-reuse cases distinguish zero, equivalent, and different rendered outcomes correctly.
- [x] Difference Regions and Cause Envelopes include every possibly causal host attachment and clip-resource fact under `sound_overapproximation`; partial cases revoke the guarantee.
- [x] Chromium fixtures prove the admitted raster path exactly; renderer dispositions, capability coverage, and conformance identity are updated without rewriting the raw dependency baseline.
- [x] Module, Structured Report, schema compatibility, renderer identity, scope, feature coverage, Agent, causal, ADR, roadmap, and packaging documentation describe the implemented and guarded boundaries.
- [x] Relevant MoonBit and repository gates pass, including browser, renderer, compatibility, schema, mutation, adversarial, performance, determinism, and Agent suites.
