## Description
Prove that disjoint subject-specific Visual Events retain only their own rendered Difference Region instead of inheriting scene-wide changed pixels.

## Design
Add independent subject-region expectations to the disjoint paint adversarial manifest. Resolve each event's primary Subject Alignment to its authored subject ID, require one exact CSS/pixel region and event-local rendered magnitude, and prove the two regions are spatially disjoint. Retain the existing Changed Fact attribution checks.

## Acceptance Criteria
- [x] The adversarial manifest independently declares expected regions for both disjoint subjects.
- [x] Each Visual Event resolves through its Subject Alignment to exactly one expected authored subject.
- [x] Each event region has exact subject-local bounds, changed-pixel count, viewport fraction, and rendered-outcome count.
- [x] Subject regions are spatially disjoint and together account for the scene changes without either event receiving the scene-wide total.
- [x] Existing cross-event Changed Fact exclusion remains enforced.
- [x] Documentation records the current supported-slice localization guarantee.

## Close Notes
Added independent subject-region oracles to the disjoint-paint adversarial manifest. The validator resolves each Visual Event's primary Subject Alignment to one authored subject and requires the exact fixed-profile CSS bounds, changed-pixel count, viewport fraction, and event rendered-outcome count.

The `left` event now proves one `(1, 4, 5, 5)` region with 25 changed pixels, and `right` proves one `(10, 4, 5, 5)` region with 25 changed pixels. The bounds are disjoint and together account for the 50 scene pixels without either subject-specific event absorbing the scene-wide total. Existing event-local Changed Fact and Cause Envelope exclusion remains enforced in the same case.

Documented this as a supported-slice guarantee for axis-aligned opaque subjects under the fixed profile; transformed and composited subject localization remains separate roadmap work.
