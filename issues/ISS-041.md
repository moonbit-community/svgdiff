## Description
Add deterministic property tests proving that unsupported inputs can never produce complete equality.

## Design
Generate reviewable unsupported families for elements, attributes, viewport semantics, CSS, paint/resources, and compositing. Self-compare every generated SVG and reject the unsafe conjunction of complete status and an empty Atomic Difference list. Also require Diagnostics and limited or failed feature coverage.

## Acceptance Criteria
- [x] Unsupported element families are generated directly and under groups.
- [x] Unsupported attributes are generated across every supported basic shape.
- [x] Deferred viewport, CSS, paint/resource, and compositing families are covered.
- [x] Every generated case forbids complete equality and requires explicit coverage limitation.
- [x] Newly discovered non-identity `viewBox` and `preserveAspectRatio` false-complete cases are guarded without rejecting identity view boxes.
- [x] The deterministic property suite is documented and runs under `moon test`.
