## Description
Evaluate the official learned LPIPS metric against the curated SVG corpus without extending canonical report semantics. The experiment must make its neural-network implementation, learned weights, base-network weights, raster source, output scale, alpha background, preprocessing, runtime, and source hashes explicit. It must measure identity, symmetry, scale/background sensitivity, renderer-gap false identity, and disagreement with the current single-pass human tiers.

This item may accept LPIPS only as an optional offline development experiment. It must never use LPIPS as an SVG equality oracle, coverage repair, Difference Magnitude, Impact input, Agent evidence, release gate, or default dependency.

## Design constraints
- Use the official LPIPS implementation and a pinned learned AlexNet configuration; do not reimplement or silently substitute an uncalibrated feature network.
- Keep PyTorch, Torchvision, LPIPS, pretrained weights, and their licenses outside the MoonBit module and default validation path.
- Composite pinned-renderer RGBA8 onto an explicit opaque sRGB background and normalize RGB to the official `[-1, 1]` input convention.
- Record at least two explicit raster scales and two explicit backgrounds so profile sensitivity is measured rather than hidden.
- Record forward and reverse values and reject the artifact if symmetry drift exceeds a declared tolerance.
- Preserve production analysis status and renderer capability gaps; a learned score cannot restore missing pixels or completeness.
- Check in a deterministic result artifact and a dependency-free validator. Regeneration may be an explicitly opt-in command requiring the pinned external stack and cached weights.
- Do not add Structured Report fields, Comparison Profile inputs, schema changes, Impact components, severity thresholds, or equality rules.
