## Description
Schema `1.41` exposes an event-local LDR-FLIP map but deliberately leaves pooling to a later contract. Agents should not have to decode a quantized spatial payload or invent a sampling domain to distinguish a small intense event from a diffuse low-error response.

## Design
Add optional invariant-checked `ComparisonProfile.flip_error_threshold`. It is a finite FLIP error value in `[0, 1]`, has no default, and is exposed by CLI option `--flip-error-threshold VALUE`. It is a reporting threshold only: it is not a just-noticeable difference, visibility decision, severity boundary, equality oracle, or Impact Assessment policy.

Every computed `PerceptualFlipEvidence` gains required `statistics` derived directly from the unquantized internal event-local FLIP map. The versioned `event_local_ldr_flip_pooling/v1` object records the canvas pixel count, selected event pixel count, response pixel count, whole-canvas arithmetic mean, selected-event-pixel arithmetic mean, nearest-rank p95 over the serialized complete response bounds, and maximum response. The canvas mean treats every pixel outside the complete response bounds as exact zero. The event mean samples exactly the raw-different pixels selected by the event's Difference Regions. Response p95 uses index `ceil(0.95 * response_pixel_count) - 1`; an empty map reports zero means, p95, and maximum with zero event and response counts.

When the caller supplies a threshold, statistics additionally record the exact threshold, count of complete-response pixels strictly greater than it, and that count divided by the whole canvas pixel count. When absent, `area_above_threshold` is null rather than silently using NVIDIA's CLI default test threshold or any guessed perceptual boundary. Maximum is mathematically canvas-independent because pixels outside the response are zero, but remains named as a response statistic to expose its sampling domain.

Statistics must not be reconstructed from uint16 base64. Map quantization remains a transport representation only. Preserve raw transparent-canvas evidence, DeltaEOK, Difference Regions, equality, Diagnostics, causes, coverage, and ordering. Advance the module and Structured Report schema, archive Schema `1.41` and one canonical report, and update compatibility and Agent evidence. Schema `1.42` and module `0.5.22` are the target identities.

## Notes
- NVIDIA FLIP v1.7 computes its standard mean over every image pixel and separately offers weighted pooled summaries. Its CLI default `0.05` is a user-overridable pass/fail threshold for a chosen aggregate, not a per-pixel visibility or area definition, so this contract does not adopt it implicitly.
- Area above threshold uses strict `value > threshold`, matching the reference CLI's failure comparison and making thresholds `0` and `1` well-defined.
