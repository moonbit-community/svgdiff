## Description
Define the benchmark contract for deciding whether an agent without image access can recover difference kind, magnitude, location, possible causes, and coverage limitations from a Structured Report alone.

## Design
Specify the allowed benchmark inputs, canonical task prompt, answer fields, evidence-traceability rules, scoring dimensions, hard safety failures, and case-level ground-truth requirements. Keep corpus construction, automated scoring implementation, numeric release thresholds, and natural-language style grading in later roadmap items.

## Acceptance Criteria
- [x] The specification prohibits image, source SVG, and hidden renderer access during agent evaluation.
- [x] The expected answer independently represents coverage, difference kind, magnitude, location, possible causes, and main-change interpretation.
- [x] Every factual answer can cite stable report IDs or Diagnostics, and missing evidence cannot be rewritten as zero or equality.
- [x] Scoring dimensions and hard safety failures are defined without prematurely selecting regression thresholds.
- [x] The specification defines the labels future corpus cases must provide.
