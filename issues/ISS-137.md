## Description
The Phase 7 roadmap combines explicit evidence states with two intentionally rejected product shapes: pure XML formatting variation as a Visual Difference and uncalibrated `subtle` or `salient` severity labels. Reconcile the item with ADR 0027 and ADR 0089 while preserving the useful requirement that Agents can distinguish supported source-only, computed-equivalent, computed-different/rendered-zero, rendered-nonzero, partial, and failed outcomes from report fields.

## Design constraints
- Pure attribute order, quote style, tag-closing style, entity spelling, declaration whitespace, and source-offset movement remain outside Visual Differences.
- Do not add raw XML text diff, byte equality, or a formatting-only outcome field to Structured Report.
- Preserve supported authored representation changes such as `red` versus `#ff0000` as source-semantic, computed-equivalent, rendered-zero differences.
- Preserve computed-different/rendered-zero separately from computed-equivalent.
- Use `analysis_status`, coverage, and Diagnostics for partial and failed outcomes.
- Keep raw magnitude and Impact evidence; do not emit `subtle`, `salient`, `major`, or other uncalibrated severity classes.
- Retain deferred severity-label work with the Impact recalibration prerequisites rather than deleting it.

## Acceptance Criteria
- [x] Canonical-example validation directly checks source-only computed equivalence, computed-different/rendered-zero, rendered-nonzero, partial, and failed states through explicit report fields.
- [x] Current Agent documentation provides a deterministic field-reading table for those outcome states.
- [x] Documentation states that pure XML formatting variation is intentionally absent and cannot be distinguished from byte-identical input through Structured Report alone.
- [x] Roadmap correctness rules and the Phase 7 checklist match ADR 0027 and ADR 0089.
- [x] A separate Deferred checklist item retains calibrated subtle/salient classification work and its prerequisites.
- [x] No Schema, module, renderer, Impact-policy, or canonical report-byte change occurs.
- [x] Focused and full relevant gates pass.
