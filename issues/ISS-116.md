# ISS-116: Implement deterministic alpha and luminance masking

## Description
Implement static local SVG masking for a deterministic bounded slice, including alpha and luminance interpretation, `maskUnits`, `maskContentUnits`, mask-region defaults, and isolated application to leaf or container content. Replace the comparison-wide masking guard with precise per-host and per-resource coverage so a text-only Agent can identify the attachment, mask mode, region, content, affected consumers, numeric magnitude, and conservative location of every admitted difference.

## Design
Resolve the non-inherited single-layer `mask` shorthand through the existing author cascade, CSS-wide values, bounded custom-property substitution, and local-reference grammar. Admit `none` and one local reference to an SVG `mask`; keep CSS image masks, multiple mask layers, positioning/compositing subproperties, external fetches, animation, nested effects, and otherwise unsupported syntax source-visible behind precise Diagnostics. Resolve `mask-mode` on the host and `mask-type` on the resource so explicit `alpha` or `luminance` overrides `match-source`, whose SVG-resource result is the mask's computed type.

Admit a static mask containing exactly one direct non-rounded solid-filled rectangle with supported color and alpha, no stroke, and deterministic axis transforms. Support both `userSpaceOnUse` and `objectBoundingBox` for `maskUnits` and `maskContentUnits`, including the normative default region of `-10% -10% 120% 120%`, percentage/fraction conversion, and zero-or-negative region suppression. Render the target and descendants into an isolated transparent layer, render the mask content into a separate RGBA layer clipped to the mask region, derive mask values from alpha or sRGB luminance times alpha, multiply the target alpha, then source-over composite the result. Guard `linearRGB` mask interpolation until its transfer function is implemented and conformance-proven.

Treat a missing, wrong-kind, empty, or otherwise undisplayable single SVG mask layer as transparent black where the specification determines that result; retain exact source evidence and distinguish this deterministic suppression from unsupported external acquisition or unsupported multi-layer syntax. Compute separate before/after conservative effect bounds from the intersection of the target's unmasked painted bound, the resolved mask region, and the transformed mask-content rectangle. Their union localizes attachment and resource events; empty intersections prove zero contribution, while unavailable host bounds revoke causal completeness instead of fabricating a location.

## Acceptance Criteria
- [x] `mask` resolves through presentation attributes, inline style, stylesheets, CSS-wide values, and custom properties without becoming inherited.
- [x] `mask-mode` and `mask-type` resolve `alpha`, `luminance`, and `match-source` with exact winning-declaration provenance and deterministic invalid-value fallback.
- [x] Local, missing, external, invalid, wrong-kind, empty, and unused mask resources have specification-correct, source-located outcomes under an explicit Resource Outcome Policy exception.
- [x] One static non-rounded solid rectangle supports both `maskUnits` and `maskContentUnits` coordinate systems, normative default/partial region attributes, percentages or fractions, deterministic axis transforms, and leaf or container application.
- [x] Alpha masking uses content alpha; luminance masking uses non-premultiplied sRGB coefficients multiplied by content alpha, with color and opacity changes reported independently.
- [x] The target subtree and mask content are isolated before mask multiplication and source-over compositing; overlap, backdrop, nesting, clipping order, transforms, and sibling order have exact tests.
- [x] Unsupported multi-layer/image masks, mask-border syntax, multiple or curved content, paint servers, nested mask/filter/clip effects, animation, use-host attachment, unsupported transforms, and `linearRGB` retain exact source facts and precise coverage Diagnostics rather than guessed pixels.
- [x] Host attachment/mode changes and resource presence, units, region, type, transform, geometry, color, and alpha changes produce typed Atomic Differences with source provenance, consumer fan-out, deterministic same-domain ordering, and continuous numeric magnitudes where applicable.
- [x] Each complete affected host has separate before/after conservative effect bounds; event localization uses their union, preserves proven empty outcomes, and excludes unrelated scene regions.
- [x] Difference Regions and Cause Envelopes contain every possibly causal host attachment and mask-resource fact under `sound_overapproximation`; partial cases revoke that guarantee.
- [x] Chromium fixtures prove every admitted raster path exactly; renderer dispositions, capability coverage, and conformance identity are updated without silently broadening dependency claims.
- [x] Module, Structured Report, schema compatibility, scope, feature coverage, Agent, causal, ADR, roadmap, packaging, and resource-policy documentation describe the implemented and guarded boundaries.
- [x] Relevant MoonBit and repository gates pass, including browser, renderer, compatibility, schema, mutation, adversarial, performance, determinism, Agent, CLI, install, module, and release suites.
