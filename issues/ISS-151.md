## Description
Choose the dependency and ownership boundary for future deterministic OpenType shaping and glyph rasterization under the accepted Font Bundle contract. The decision must be grounded in current MoonBit/Mooncakes availability, upstream technical and licensing evidence, and a disposable native build/FFI probe.

This item selects and constrains a future implementation. It does not vendor upstream source, add a production dependency, implement bindings, load fonts, match families, shape text, lay out SVG text, render glyphs, or change current partial text analysis.

## Design constraints
- Prefer a maintained MoonBit community package only if it exposes the required deterministic controls, exact upstream identity, source/license evidence, bounded memory APIs, and a narrow stable seam.
- If no package qualifies, choose separately versioned workspace module ownership rather than leaking C/C++ dependency types through the svgdiff public API.
- Pin upstream source identities, licenses, build systems, required transitive components, static/native target, and reproducibility-affecting build options.
- The seam must consume already verified in-memory Font Resources and explicit Font Face Locators; it may not discover system fonts, read paths, fetch URLs, or choose fallback.
- Shaping, glyph loading/outline extraction, and rasterization outputs remain distinct. Do not conflate glyph IDs, outlines, bitmaps, layout positions, or SVG Visual Events.
- Identify which capabilities are initially disabled or separately gated, including hinting, subpixel/LCD output, synthetic styles, color glyphs, SVG glyphs, bitmap strikes, Graphite/AAT, WOFF/WOFF2, and platform-native backends.
- Record determinism limits: pinned source/build/profile can support repeatability but cannot be inferred from library names alone.
- Keep dependency licensing and future distribution obligations explicit; do not treat license compatibility as a legal opinion.
- Do not change Structured Report, Comparison Profile, module dependencies, public MoonBit interfaces, current text Diagnostics, default CI, or release assets.
