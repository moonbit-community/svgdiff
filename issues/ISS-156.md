## Description
Decide how event-driven CSS pseudo-classes and user-interaction state are declared, validated, and reproduced without importing ambient pointer, focus, navigation, history, device, or browser state into deterministic comparison. Separate a requested semantic state from the action sequence or browser behavior that may produce it.

This item records a state/profile boundary. It does not implement pseudo-class selector matching, dispatch events, synthesize pointer or keyboard input, execute scripts, add a browser mode, define animation time, change the current static Comparison Profile, or weaken current equality and completeness claims.

## Design constraints
- Preserve the current interaction-free deterministic static profile and its existing coverage guards.
- Classify interaction-dependent pseudo-classes by the state and authority needed to evaluate them rather than treating all pseudo-classes as one boolean set.
- Separate declarative requested state, validated derived state, action/event traces, target-specific observed state, and resulting visual evidence.
- Define exact identities for URL/target, pointing devices and hit testing, hover/active chains, focus and focus-visible state, keyboard modality, form/control state where relevant, and unsupported privacy- or history-dependent state.
- Record hierarchy and exclusivity invariants so impossible or ambiguous state cannot silently match selectors.
- Keep action replay and state equivalence distinct; two traces may reach the same state, while one trace may produce target-dependent events.
- Preserve failure, unavailable target, invalid state, unsupported pseudo-class, ambiguous hit target, replay divergence, and ambient state as typed non-equality outcomes.
- Define the relationship to script observations, future animation timelines, resources, renderer/browser profiles, and text-only Agent interpretation.
- Do not add product code, dependencies, public APIs, report fields, Schema changes, Diagnostics, CLI flags, fixtures, default CI work, or release assets.
