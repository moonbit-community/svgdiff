## Description
Add reproducible generated SVG pairs whose mutation specification names the changed authored fact and affected visual subjects before the comparison engine runs.

## Design
Use one-value SVG templates and a versioned JSON mutation specification. A deterministic standard-library generator substitutes the declared before and after values and emits a generated manifest containing the expected Changed Fact and affected subject IDs. Validate those expectations through the production CLI. Do not infer ground truth from the report being tested.

## Acceptance Criteria
- [x] Mutation specs identify the template, property, before and after values, and expected affected subjects.
- [x] Generation is deterministic and rejects missing or repeated placeholders.
- [x] Generated pairs include direct paint, geometry, and inherited paint examples.
- [x] An automated check confirms the production report retains each known Changed Fact and affected subject set.
- [x] Generated artifacts are temporary and do not duplicate the curated hand-authored corpus.
