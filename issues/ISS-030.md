## Description
Build an evaluation harness that presents only Structured Report JSON and the fixed acceptance prompt to a text-only agent adapter, then records structurally valid answer records for later scoring.

## Design
Keep report generation outside the harness. The `prepare` stage scans only a directory of report JSON files and emits one JSONL task per report. The `run` stage sends each task to a configured subprocess through stdin and accepts one JSON answer through stdout. Validate the answer protocol locally, but defer semantic metric computation and regression thresholds to later roadmap items.

## Acceptance Criteria
- [x] Harness task creation reads only Structured Report JSON and a fixed prompt, not SVGs, images, or hidden labels.
- [x] Every task records a case ID, acceptance-contract version, prompt, and complete report.
- [x] The agent adapter protocol uses JSON on stdin and stdout and detects command failure, timeout, invalid JSON, or mismatched case IDs.
- [x] A versioned answer schema covers coverage, differences, magnitude claims, locations, possible causes, main changes, and limitations.
- [x] An integration test runs all curated reports through a report-only test adapter and confirms no hidden artifact enters the task records.
