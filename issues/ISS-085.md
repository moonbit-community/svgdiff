## Description
Test byte-identical canonical Structured Reports across the project's explicitly supported operating-system and architecture matrix.

## Design
Define the tested matrix as Ubuntu 24.04 x64, Windows Server 2025 x64, and macOS 15 arm64 on GitHub-hosted runners. Each runner builds the same revision in native release mode and emits a platform-neutral bundle containing default and compact canonical reports for every versioned determinism case. A separate aggregation job compares exact bundle inventories and bytes across all three platforms.

Keep runner identity and toolchain observations outside the compared bundle. Add a local comparator harness with identical-bundle, divergent-byte, and missing-file controls so aggregation semantics can be verified without pretending one host is three platforms. Do not publish native binaries or claim cross-version identity in this item.

## Acceptance Criteria
- [x] The supported test matrix names exact operating-system labels and expected architectures.
- [x] Every matrix entry builds the release CLI and captures both canonical JSON modes for the full determinism corpus.
- [x] A platform-neutral manifest binds every compared path to its case, mode, and SHA-256 digest.
- [x] Aggregation fails on any byte divergence, missing report, extra report, or incomplete platform matrix.
- [x] Local positive and negative controls test the aggregation policy independently of GitHub runners.
- [x] Current determinism, security, CI, ADR, and roadmap documentation state the tested guarantee and its limits.
- [x] Binary publication and cross-version reproducibility remain separate roadmap work.
