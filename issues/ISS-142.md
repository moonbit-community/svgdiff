## Description
Add an optional deterministic natural-language presentation derived from an existing Structured Report. The summary should help a human or text-only Agent orient quickly, while remaining explicitly non-authoritative and preserving the canonical JSON report as the only source of truth.

Expose the presentation as Markdown through a public library function and an additive CLI file option. It must repeat report-local IDs and direct report values rather than inventing visual interpretation, severity, visibility, equality, or unique-cause claims.

## Design constraints
- Add `render_markdown_summary(report)` as a pure presentation over an already computed report; do not run comparison again.
- Add `--summary FILE` as a side artifact analogous to `--html FILE`; stdout remains canonical JSON or the selected Agent transport.
- State prominently that the Markdown is derived, incomplete presentation and that Structured Report JSON remains authoritative.
- Include analysis status, report counts, Impact policy/status/calibration/frontier, every Atomic Difference, and every Diagnostic.
- Preserve exact report-local IDs, domains, source before/after values, computed relation status and reason, evidence-layer names, Impact measurements, and Diagnostic codes.
- Describe frontier ties, incomparability, unavailable measurements, and partial status without introducing an order or calibrated label.
- Never emit `subtle`, `salient`, `major`, visible/invisible, equal/identical, or proven/unique cause judgments from raw evidence.
- Escape report-controlled text so it cannot become Markdown structure or raw HTML.
- Keep Structured Report Schema `1.43`, Agent projection, renderer, ordering, Impact, default JSON, compact JSON, JSONL, HTML, and exit-status behavior unchanged.
