# ISS-117: Implement bounded static filter primitive graphs

## Description
Implement the first complete SVG filter-graph execution slice rather than treating every filter as an opaque unsupported attribute. The slice must give a text-only Agent the winning host attachment, resource and primitive graph changes, named intermediate dependencies, continuous offset magnitudes, conservative effect bounds, final raster evidence, and exact source provenance.

## Design
Resolve the non-inherited `filter` property through the existing author cascade, CSS-wide values, bounded custom-property substitution, and local-reference grammar. Admit `none` and one same-document SVG `filter` reference. A missing or wrong-kind local target deterministically applies no filter, and an empty filter deterministically suppresses the host. A nonempty complete filter contains direct static `feOffset` primitives. Each primitive accepts `SourceGraphic`, `SourceAlpha`, the immediately preceding result, or a named result from an earlier primitive; forward, missing, reserved, ambiguous, or unsupported inputs remain precise Diagnostics. The final primitive is the primary output.

Resolve `filterUnits`, `primitiveUnits`, the normative filter-region defaults `-10% -10% 120% 120%`, integer device-pixel offsets, and omitted primitive subregions. Render the host into an isolated transparent SourceGraphic surface, derive SourceAlpha when requested, evaluate each primitive into a separate intermediate surface, hard-clip inputs and outputs to the filter region, then source-over composite the final surface in ordinary stacking order. Admit explicit-ID, untransformed static basic-shape leaf hosts without clip, mask, opacity, animation, reuse, or another effect interaction; retain exact source facts and revoke rendered completeness outside that boundary.

Propagate a conservative bound with every intermediate: SourceGraphic and SourceAlpha start at the host painted bound, `feOffset` translates its input bound, and every result intersects the filter region. The final bound localizes host and resource events; a clipped-empty result proves zero contribution. Other primitives, CSS filter functions, external acquisition, filter templates, explicit primitive subregions, fractional device offsets, transformed coordinate systems, dynamic content, and effect interactions are non-goals for this issue and must remain source-visible behind precise guards.

## Acceptance Criteria
- [x] `filter` resolves through presentation attributes, inline style, stylesheets, CSS-wide values, and custom properties without becoming inherited.
- [x] Local, missing, external, invalid, wrong-kind, empty, and unused filter resources have deterministic source-located outcomes.
- [x] Static `feOffset` graphs resolve SourceGraphic, SourceAlpha, implicit previous results, and named earlier results while rejecting forward or unresolved references.
- [x] `filterUnits`, `primitiveUnits`, normative filter-region defaults, percentages/fractions, and integer device offsets are resolved with exact provenance.
- [x] Every primitive receives a distinct intermediate RGBA surface, applies a hard filter-region clip, and preserves ordinary sibling stacking.
- [x] Host attachment, resource units/region, primitive insertion/deletion/input/result, and dx/dy changes produce typed Atomic Differences with continuous numeric magnitudes and consumer fan-out.
- [x] Per-side conservative intermediate and final effect bounds localize occupied and vacated outcomes, including clipped-empty results.
- [x] Difference Regions and Cause Envelopes contain every possibly causal admitted filter fact under `sound_overapproximation`; partial cases revoke the guarantee.
- [x] Unsupported primitives, CSS filter functions, templates, primitive subregions, fractional offsets, transforms, animation, reuse, and effect interactions retain exact source facts and precise Diagnostics.
- [x] Chromium fixtures prove every admitted raster path exactly; renderer dispositions, capability coverage, and conformance identity are updated without broadening the raw dependency claim.
- [x] Module, Structured Report, schema compatibility, scope, feature coverage, Agent, causal, ADR, roadmap, packaging, and version documentation describe the implemented and guarded boundaries.
