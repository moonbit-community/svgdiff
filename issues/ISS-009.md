## Description
For every Difference Region, list candidate Changed Facts so the set necessarily contains every actual changed cause whenever the report claims causal completeness.

## Design
Implement the accepted safe fallback first: for a fully covered supported region, intersect conservative per-subject may-influence facts from both inputs; whenever a sound independence rule is unavailable, widen to all Changed Facts in the comparison. Unsupported semantics revoke the guarantee and retain candidates with `not-established` coverage.

## Acceptance Criteria
- [x] Movement unions before and after influence.
- [x] Insertion and deletion include the relevant presence fact.
- [x] Shared inherited paint includes its ancestor Changed Fact for every affected region.
- [x] Unknown or unsupported operations widen candidates or revoke the guarantee; they never silently prune.
- [x] Mutation-style fixtures establish actual causes are subsets of reported candidates.
- [x] Targeted tests and native checks pass.
