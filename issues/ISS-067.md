## Description
Make the current event-region provenance pruning explicit and executable so unrelated Changed Facts from disjoint events do not inflate complete Cause Envelopes.

## Design
For a complete `event_region` envelope, require the candidate set to equal the union of Changed Facts referenced by that Visual Event's Atomic Differences. For a `comparison` fallback, require the complete report fact universe. Retain false positives within an event because finer tile contribution is not yet proven. Add a negative control that injects a valid but unrelated fact from another event.

## Acceptance Criteria
- [x] Complete event-region envelopes contain exactly their Visual Event's Changed Facts.
- [x] Complete comparison fallbacks contain the complete report Changed Fact universe.
- [x] Disjoint multi-event reports demonstrate removal of at least one unrelated fact per region.
- [x] Candidate pruning never changes the actual-cause containment property.
- [x] A cross-event contamination negative control is rejected.
- [x] Documentation distinguishes current event-region pruning from future finer tile provenance.

## Close Notes
Made the current event-region provenance rule executable in the production-report validator. A complete `event_region` envelope must contain exactly the union of Changed Facts referenced by its Visual Event's Atomic Differences. A complete `comparison` fallback must contain the full report fact universe. Partial fallback behavior remains independently enforced.

The existing disjoint two-event adversarial report demonstrates useful pruning: each region retains its event's one fact and removes the other event's fact. Added a negative control that injects the second event's valid fact into the first region; reference integrity alone would accept it, but the causal precision gate rejects the cross-event contamination.

The bidirectional mutation property still retains every actual cause across thirty-six complete comparisons and 130 regions, proving the pruning rule did not weaken soundness. Documented that facts within one Visual Event remain conservatively grouped until finer tile-level provenance is justified.

Verified generated interfaces and formatting, warning-clean native checks, all 103 MoonBit tests, report determinism and five negative controls, deterministic adversarial attribution-leakage coverage, forty directional mutation reports and causal property, evaluation metrics, reproducible benchmark pass/fail behavior, Python and shell syntax, local Markdown links, and `git diff --check`.
