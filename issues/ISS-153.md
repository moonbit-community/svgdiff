## Description
Define the product and evidence boundary for deterministic color management beyond the current fixed v1 sRGB interpretation. Decide which predefined wide-gamut, embedded ICC, HDR, transfer, interpolation, compositing, gamut-mapping, tone-mapping, and output-observation choices can become separately identified future Comparison Profiles without weakening current equality or completeness claims.

This item records a profile architecture and staged support boundary. It does not convert a color, decode a newly admitted raster, add a report field, change current Diagnostics, select a production dependency, implement HDR display behavior, or reinterpret existing Schema `1.44` reports.

## Design constraints
- Preserve current v1 sRGB source interpretation, linear-light premultiplied raster math, perceptual-background separation, and out-of-profile Diagnostics unchanged.
- Separate authored/source color spaces, interpolation spaces, linear working/compositing representation, perceptual-measurement space, and output/display observation; one generic `wide_gamut` flag is insufficient.
- Treat predefined mathematical spaces separately from arbitrary embedded ICC transforms and from HDR viewing/tone-mapping policy.
- Require every future canonical profile to close transform algorithms, numeric precision, chromatic adaptation, rendering intent, black-point behavior, gamut policy, alpha/compositing order, resource identity, limits, and target dependence.
- Preserve source evidence and precise partial coverage whenever a profile cannot admit an input; never silently clip, retag, guess a display, or substitute a platform color-management stack.
- Keep external browser/platform pixels observational unless separately admitted by the later renderer-profile decision.
- Record staged candidates, permanent non-goals, rejected alternatives, implementation prerequisites, and reconsideration gates.
- Do not add product code, dependencies, public APIs, Structured Report fields, Schema changes, CLI flags, default CI work, or release assets.
