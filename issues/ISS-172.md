## Description
The CI determinism matrix still invokes the pre-owner-rename native build path `_build/native/release/build/cmd/svgdiff/svgdiff.exe`. Current MoonBit output exists only at `_build/native/release/build/Milky2018/svgdiff/cmd/svgdiff/svgdiff.exe`, so every supported-platform bundle job would fail before producing reproducibility evidence.

## Design constraints
- Change only the stale CI path and add a focused regression assertion to the existing cross-platform determinism test.
- Keep the module owner, package path, binary name, determinism bundle protocol, supported matrix, and release workflow unchanged.
