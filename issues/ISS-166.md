## Description
Validate the M5 milestone claim that every currently non-adopted advanced capability is explicitly documented and cannot silently produce complete equality. Compose the accepted font, color, multi-renderer, script, interaction, animation, foreign-content, resource-snapshot, and platform-observation decisions with current product coverage guards and machine-checkable negative controls.

This item does not adopt an advanced profile. It validates the safe boundary between current canonical static analysis, separately identified external observations, future profile contracts, and permanent non-goals.

## Design constraints
- Inventory each advanced capability by stable ID, current disposition, governing document, decision artifact, validation command, and product guard or non-applicability reason.
- Distinguish permanent canonical non-goals, future separately profiled capabilities, target-local observations, and unimplemented accepted contracts.
- Require current encountered unsupported semantics to reduce analysis coverage or fail admission through explicit Diagnostics; never infer support from matching raw pixels or empty optional arrays.
- Keep browser, platform, and external-observation evidence outside canonical equality, magnitude, Impact, regions, and causes unless a future profile explicitly adopts it.
- Keep comparison-time network/filesystem acquisition, ambient fonts, scripts, actions, clocks, host layout, display state, and renderer consensus outside current authority.
- Do not claim that merely documented future identities are implemented.
- Do not change product code, public APIs, Structured Report Schema, profile or policy identities, CLI behavior, fixtures, dependencies, default CI, or release assets unless a verified defect requires a separate scoped fix.
