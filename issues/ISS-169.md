## Description
Restore the deterministic production-boundary fuzz gate after the HTML evidence UI added an `aria-label` to the embedded report textarea. The generated HTML remains valid and the security validator already accepts additive and reordered attributes, but the fuzz validator still requires the obsolete exact opening tag `<textarea id="report-data" readonly>`.

## Reproduction

```sh
python3 evaluation/fuzz/run.py \
  --cli _build/native/release/build/Milky2018/svgdiff/cmd/svgdiff/svgdiff.exe \
  --seed 20260714 --cases 24 --case-index 0 \
  --output /tmp/svgdiff-fuzz-case0.json
```

The command deterministically fails with `report JSON textarea is missing`. Case index 1 fails identically, proving hostile source text is not the cause. The actual tag is `<textarea id="report-data" readonly aria-label="Complete Structured Report JSON">`.
