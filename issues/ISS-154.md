## Description
Decide whether future multi-profile analysis compares one engine under different execution profiles, different engines or browsers under the same declared profile, or both. Define how those questions remain distinguishable so an Agent can identify stable visual differences, profile-sensitive outcomes, and renderer divergences without treating a majority of pixels as truth or attributing a confounded engine-plus-profile change to one cause.

This item records comparison semantics and an evidence container boundary. It does not add another renderer, run a new browser, add a product mode, change the Structured Report, implement a matrix, admit platform profiles, or weaken current single-profile equality and completeness claims.

## Design constraints
- Preserve one current Structured Report as a comparison of before and after under one exact Comparison Profile, renderer identity, and renderer-conformance identity.
- Separate same-engine profile sensitivity from same-profile cross-engine conformance; never hide both behind one generic `renderer_diff` relation.
- Treat a simultaneous engine and profile change as confounded unless it is decomposed through compatible matrix cells sharing one axis at a time.
- Define exact cell and edge compatibility, identity, coverage, evidence, error, and claim limits.
- Keep canonical project-engine results separate from external browser/platform observations and from renderer-conformance dispositions.
- Preserve every disagreement and unavailable result; do not average, vote, threshold, or pick the most common renderer as semantic truth.
- Define how a text-only Agent can report invariant, profile-sensitive, engine-sensitive, confounded, and insufficient-evidence outcomes with direct links to cell evidence.
- Preserve the platform font and color observation boundaries plus later cross-browser/platform implementation roadmap items.
- Do not add product code, dependencies, public APIs, report fields, Schema changes, CLI flags, fixtures, default CI work, or release assets.
