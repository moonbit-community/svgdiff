## Description
Reject comparisons that exceed deterministic resource budgets before the engine performs unbounded parsing, semantic analysis, rendering, region extraction, or report delivery.

## Design
Keep the public comparison API unchanged and apply fixed, versioned safety defaults. Check UTF-8 input bytes before XML parsing; count XML elements, nesting depth, path-data tokens, and local references in one event-stream pass; validate viewport dimensions and raster pixel area before rendering; and validate total Difference Regions plus compact UTF-8 report bytes before returning the report. Any exceeded budget returns a small `failed` report with stable `resource_limit_exceeded` Diagnostics rather than a truncated inventory.

Use an internal limits record so whitebox tests can exercise exact boundaries without weakening the production defaults or prematurely adding a configurable public API. The report-size check bounds deliverable output, not transient peak memory during serialization; cancellation and time budgets remain separate roadmap work.

## Acceptance Criteria
- [x] Input UTF-8 byte size is checked before XML parsing for both sources.
- [x] Element count, path-data complexity, nesting depth, and local-reference count are checked in one namespace-aware XML event pass.
- [x] Viewport dimensions and total raster pixels are checked before rendering.
- [x] Total Difference Regions and both built-in report JSON serializations are checked before returning a report.
- [x] Every exceeded budget returns `analysis_status = "failed"`, a bounded schema-valid report, stable Diagnostic evidence, and no misleading truncated difference inventory.
- [x] Exact-limit and one-past-limit tests cover all eight dimensions, including non-ASCII UTF-8 byte accounting.
- [x] Current contracts, feature coverage, version identities, canonical examples, and compatibility evidence document the behavior.

## Close Notes
Added fixed, versioned production budgets for 8 MiB per input, 100,000 elements, 1,000,000 path-data lexical units, depth 256, 100,000 references, 8,192 pixels per raster axis and 16,777,216 total pixels, 65,536 Difference Regions, and 32 MiB per built-in JSON serialization. Input bytes are counted incrementally before XML parsing; structure budgets share one streaming namespace-aware pass; raster dimensions are rejected before rendering; and region extraction and event attachment stop at the first excess. Report bytes are checked for both compact and indented JSON, with the documented limitation that this is an output bound rather than a peak-memory bound.

Every overrun returns a small `failed` report with `resource_limit_exceeded`, stable dimension subjects, failed `resource.*` coverage rows, the first applicable source span, and empty semantic inventories rather than truncated evidence. Added exact and one-past whitebox coverage for all eight dimensions, non-ASCII UTF-8 accounting, dual-input ordering, source localization, non-truncation, and the fixed default values; added a CLI exit-status case and a canonical production resource-failure report.
