# ISS-080: Reject cyclic and explosive local reference graphs

## Description
Detect local SVG reference cycles and acyclic `<use>` graphs whose transitive cloning cost can grow far beyond the authored element count, before the pinned parser or renderer expands them.

## Design
Build a conservative, project-owned local-reference graph from the bounded namespace-aware XML stream. Preserve ID-bearing definition scopes and reference attribute spans. Include `<use href>` edges to any local target and resource dependencies formed by local `href` or `url(#...)` references to gradients, patterns, markers, clips, masks, filters, and symbols. Attach descendant references to every containing ID scope so cloning an ancestor cannot hide a nested dependency.

Detect cycles with an iterative depth-first traversal rather than recursive graph code. On the acyclic `<use>` subgraph, evaluate a saturating transitive expanded-element upper bound in reverse topological order, retaining repeated edges because repeated instances multiply work. Reject before `mizchi/svg` parsing when the graph cycles or the expansion bound exceeds the fixed production budget. Conservative duplicate-ID merging and ancestor propagation may report false positives, but must not omit a real local cycle or expansion represented by the accepted edge grammar.

XML entity recursion remains owned by `Milky2018/xml`'s separate depth and expansion budgets. External resources remain unfetched. Complete SVG resource semantics remain roadmap work; this item is an admission guard, not a resource resolver.

## Acceptance Criteria
- [x] Local `<use>` and resource-reference edges retain source-role-qualified attribute spans.
- [x] Self-cycles and multi-node cycles are rejected before renderer parsing without recursive graph traversal.
- [x] Acyclic repeated-use graphs are assigned a saturating transitive expansion upper bound and rejected at the first one-past-budget case.
- [x] Missing, external, and non-expanding references do not fabricate a cycle or expansion cost.
- [x] Duplicate IDs and nested ID scopes are handled conservatively without losing a possible edge.
- [x] Failed reports contain stable cycle or expansion Diagnostics, failed coverage rows, and no truncated semantic inventory.
- [x] Current contracts, version identities, canonical examples, compatibility evidence, adversarial fixtures, and security guidance document the behavior and its conservative boundary.

## Close Notes
Added a project-owned, namespace-aware local-reference admission graph before `mizchi/svg` parsing. It records local `<use href>` expansion edges plus accepted resource `href` and `url(#...)` dependencies, preserves reference attribute Source Spans, propagates nested dependencies to containing ID scopes, and conservatively merges duplicate IDs. Missing targets, external fragments, and `url(#...)` targets that are only ordinary visual elements do not create graph failures.

Cycle detection uses an explicit iterative DFS. Acyclic `<use>` graphs use reverse-topological saturating cost evaluation with repeated edges retained and a fixed inclusive production budget of 1,000,000 expanded elements. Ancestor propagation is itself bounded to 1,000,000 materialized graph-edge instances and checks before appending the first excess edge, preventing the conservative closure rule from multiplying 100,000 source references by the full nesting bound in memory. Cycles return `reference_cycle_detected`; one-past expansion returns `reference_expansion_limit_exceeded`; graph materialization overflow returns source-located `resource_limit_exceeded`. All produce failed coverage and empty semantic inventories before renderer allocation.
