## Description
The report exposes one `geometry_displacement_css_px` scalar. Path differences currently populate it with the symmetric maximum nearest-boundary distance, while admitted basic geometry may populate it with an exact analytic outcome. A text-only Agent cannot tell whether most of a painted boundary stayed close while one outlier produced the maximum, and cannot inspect the sampling support behind the raster observation.

## Design
Add nullable `painted_boundary_displacement` to `DifferenceMagnitude`. Its measured object records a versioned method ID, before and after boundary sample counts, and arithmetic mean, nearest-rank p95, and maximum distances in CSS pixels. Retain `geometry_displacement_css_px` as the existing best available scalar geometry outcome; when its source is the same raster boundary observation, it equals the distribution maximum, but an independent analytic geometry outcome is not overwritten by the quantized distribution.

Define `symmetric_nearest_boundary_pixels/v1` over isolated pinned-renderer alpha support. A boundary sample is the center of a painted pixel with alpha greater than zero that touches the viewport edge or a four-connected zero-alpha neighbor. For every before boundary sample, compute the Euclidean distance to the nearest after boundary sample; repeat after-to-before and concatenate both directional arrays. The mean is the arithmetic mean of the combined samples, p95 is the nearest-rank value at `ceil(0.95 * sample_count) - 1`, and maximum is the largest sample. Divide device-pixel distances by the recorded Comparison DPR to obtain CSS pixels. The combined distribution is invariant under input reversal.

If both isolated boundaries are empty, emit a measured zero distribution with both sample counts equal to zero. If exactly one boundary is empty, image dimensions differ, isolation is unavailable, or the bounded measurement budget is exhausted, keep the object null rather than fabricate a distance. Attach one cached alignment-level observation to every related entity-role geometry Atomic Difference; multiple source differences for the same aligned painted outcome intentionally share the same distribution. Paint-only, resource-role, presence, and unaligned differences do not receive it.

Measure admitted isolated basic-shape, path, stroke, and transform outcomes under the current product renderer and coverage guards. Preserve the existing path partial-analysis and renderer-conformance Diagnostics: this observation is deterministic evidence from the pinned renderer, not proof of browser-conformant geometry. It does not establish continuous vector Hausdorff distance, pointwise semantic correspondence, signed normal displacement, subpixel alpha isocontours, soft coverage difference, color difference, perceptual importance, effect-resource localization, or font-dependent text boundaries. Those remain separate roadmap items or existing deferred scope.

Advance the module and Structured Report schema because the new required nullable object changes serialized `DifferenceMagnitude`. Archive the previous schema and canonical example, update compatibility and Agent evidence, and keep ordering policy, renderer identity, conformance profile, exact parameter scales, and Impact Assessment unchanged.
