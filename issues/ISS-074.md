## Description
Decide whether current Visual Events should aggregate across Primary Subject Alignments by spatial relationship, hierarchy, shared resources or causes, or rendered-outcome coherence.

## Design
Keep the current one-primary-alignment boundary. Treat overlap, adjacency, hierarchy, shared Changed Facts, shared resources, and similar outcomes as contextual relationships rather than event identity. Reopen only after a report-only Agent benchmark shows a concrete fragmentation failure and a proposal defines deterministic membership, ordering, traceability, magnitude and region composition, causal behavior, ambiguity, compatibility, and labeled evaluation. Do not implement aggregation in this item.
