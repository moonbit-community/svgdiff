## Question

What exactly do event and group checkboxes mean, how do hover, focus, persistent selection, filtering, expansion, and checked state interact, and which state is transient versus preserved in the generated artifact?

## Notes

- 2026-07-18: Defined Atomic Difference Review Marks as the only base checkbox state. Event and Rendered Outcome Group checkboxes are derived unchecked/mixed/checked controls over all descendants and always act on the full hierarchy despite filtering. Domain Families remain facets. Review never means accepted, ignored, resolved, equal, unimportant, or false positive.
- 2026-07-18: Accepted one persistent Event-owned Localization Selection with optional Atomic Difference inspection context. Hover and keyboard focus temporarily override and then restore it. Locate, card activation, Impact Map activation, Enter, or Space replace the selection; explicit Clear or Escape removes it. Review Marks and expansion remain independent, and multi-Event overlays are forbidden.
- 2026-07-18: Accepted separate Event-level and Atomic-level Review Filters with contains semantics for multi-value facets. Filtering changes visibility only, retains full counts, hierarchy checkbox state, ordering, review, expansion, and evidence, and reports visible/total counts. A hidden Localization Selection suspends its overlay with show/clear controls and restores when visible.
- 2026-07-18: Accepted independent Evidence Disclosure State. Event and child evidence sections expand separately; card activation, Locate, checkbox, filters, and disclosures each have one effect. Evidence links may open and focus canonical detail without changing review. No accordion auto-close or implicit global expansion is permitted.
- 2026-07-18: Accepted session-only Review State for the first redesign: marks, selection, filters, disclosure, search, and preview view reset on reload and never use localStorage, cookies, network sync, URL source leakage, HTML mutation, or report mutation. Explicit review-state import/export remains fog pending prototype evidence.
- 2026-07-18: Accepted a Synchronized Preview View with shared Comparison Viewport zoom/pan, initial Fit Canvas, no hover/selection auto-motion, and explicit Fit Selected Localization, Fit Canvas, and Reset View commands. Navigation unions never become report regions; unlinked views remain fog pending prototype evidence.

## Close Notes

Resolved review controls as local, orthogonal state. Atomic Difference Review Marks are the only base checkbox state, with derived Event and outcome-group tri-state controls over complete descendants. One persistent Event-owned Localization Selection is temporarily overridden by hover/focus; filtering changes visibility only and suspends hidden selection overlays without losing context. Evidence disclosures are independent and links open canonical detail without mutating review. All state is session-only and resets deterministically on reload. Both previews share synchronized zoom/pan; overlay display never moves the viewport automatically, while explicit fit commands change navigation only. No interaction changes report facts, ordering, Impact, evidence, or causality.
