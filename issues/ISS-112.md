## Description
Define one normative and executable outcome policy for missing, cyclic, invalid, and unused SVG resources. Consolidate the behavior already distributed across paint servers, structural reuse, gradients, patterns, markers, images, caller bundles, and the unified resource graph so callers and text-only Agents can distinguish deterministic fallback, partial semantic coverage, failed admission, and source-only inactive differences without guessing from resource-family implementation details.

## Design
Classify each authored resource occurrence along independent axes: locator state, expected target kind, semantic validity, graph safety, and visual activity. A missing or wrong-kind local target is complete only when an implemented SVG rule deterministically selects a fallback or no-paint branch; unresolved consumers otherwise retain exact source evidence and a family-specific partial Diagnostic. External, malformed, unsupported, or invalid referenced content is partial when the bounded source remains analyzable. Malformed XML, invalid caller configuration, fixed-budget violations, accepted local-reference cycles, and explosive expansion fail admission because no complete bounded inventory can be promised.

Keep graph safety independent from reachability: every accepted local resource cycle, including an otherwise unused one, fails before semantic comparison. Keep visual activity independent from source presence: unused SVG definitions may retain resource-role source-semantic Atomic Differences with no affected rendered subjects or fabricated rendered evidence, while unused caller-bundle entries are acquisition context and produce no report differences or content-decoder Diagnostics. Global bundle shape, MIME, duplicate-key, and byte-budget validation still applies to every supplied entry before SVG analysis.

Do not introduce a new public report layer or generic Diagnostic that would erase precise family-specific codes. Record the cross-family matrix as a current contract and exercise it through end-to-end policy tests over representative resource families.

## Acceptance Criteria
- [x] A normative matrix defines locator, target-kind, validity, safety, and activity outcomes as complete, partial, or failed.
- [x] Missing and wrong-kind local paint targets remain complete through deterministic fallback or no-paint selection, while unresolved non-paint consumers remain source-located partial.
- [x] External, malformed, unsupported, and invalid referenced content remains partial unless XML, caller configuration, or a fixed safety bound prevents a usable inventory.
- [x] Every accepted local-reference cycle, including an unused cycle, fails admission with establishing source locations; missing, external, invalid, and wrong-kind targets do not fabricate cycles.
- [x] Unused SVG definition differences remain source-visible resource differences without affected-subject fan-out or fabricated nonzero rendered outcomes.
- [x] Unused caller-bundle entries do not produce visual differences or content-decoder Diagnostics, while global bundle validation and budgets still apply.
- [x] Cross-family tests cover missing, wrong-kind, external, invalid, cyclic, and unused outcomes with deterministic report status and evidence layers.
- [x] Current scope, Agent guidance, safety/resource policy, feature coverage, and ADR documentation use the same behavior vocabulary.
- [x] Relevant MoonBit and repository validation gates pass.
