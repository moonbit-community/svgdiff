## Description
Implement the SVG 2 `<url> [none | <color>]?` paint grammar for `fill` and `stroke`. Preserve the complete authored value while deterministically selecting a same-document gradient or pattern, the optional fallback paint, or no paint when the referenced ID is missing or denotes the wrong element kind.

## Design
Parse one paint value into a typed primary paint-server URL plus an optional `none`, CSS Color 3, or `currentColor` fallback. Admit ASCII whitespace, matching quotes, and percent-decoded local fragment IDs consistently with the reference-safety contract. Multiple paint layers, `context-fill`, `context-stroke`, external resource resolution, and unsupported color profiles remain outside this item.

Resolve the URL against the input document before resource semantics. An existing same-document `linearGradient`, `radialGradient`, or `pattern` wins and makes the fallback inactive. A missing ID or an ID whose element is not an admitted paint server selects the fallback; absence of a fallback selects `none`. A syntactically valid external URL remains indeterminate because the current self-contained input cannot prove whether the target resolves.

Retain source-level differences for every authored spelling. Computed paint compares only the selected branch, including `currentColor`, color alpha, `fill-opacity` or `stroke-opacity`, and leaf opacity. Gradient and pattern resource fan-out consumes only an active selected resource reference. Changing an inactive fallback is source-visible but computed-equivalent; changing target validity, the active fallback, or the active resource produces the corresponding mediated fill/stroke outcome.

- [x] Existing same-document gradients and patterns select the resource branch and leave the fallback inactive.
- [x] Missing IDs and wrong-kind local IDs select the fallback, or deterministic `none` when no fallback is authored.
