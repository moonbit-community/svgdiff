## Description
Validate that paths, transforms, viewports, CSS cascade, reuse, gradients, clipping, masking, and group compositing each have an explicit complete admitted slice or a precise partial boundary. Reconcile the M2 milestone gate against the current coverage matrix, Diagnostics, v1 scope, and executable tests without broadening any support claim.

This is a milestone acceptance gate, not authorization to relabel guarded semantics complete, implement a wider SVG slice, remove Diagnostics, or infer support from passing raster output alone.

## Design constraints
- Check each named capability independently across Source Semantics, Computed Appearance, and Rendered Evidence.
- Preserve the current guarded path result: normalized source geometry and measurements do not make general path semantics complete.
- Preserve renderer-only partial boundaries for general affine transforms, non-integer viewport mapping, and referenced-gradient rasterization.
- Preserve syntax, reference, content, geometry, unit, interaction, and effect-bound Diagnostics outside admitted CSS, reuse, clip, and mask slices.
- Treat group compositing as complete only for the admitted static container-opacity slice and its documented interactions.
- Require direct feature-coverage rows, current-scope descriptions, and focused executable tests for every capability.
- Do not change product code, public APIs, Structured Report Schema, profile or policy identities, dependencies, CLI behavior, fixtures, CI, or release assets unless the audit exposes a real gate defect.

## Acceptance Criteria
- [x] A machine-checkable gate inventory contains exactly the nine named core static capabilities.
- [x] Every capability links its accepted slice, evidence-layer boundary, partial/failure Diagnostics where applicable, and focused executable tests.
- [x] Paths remain explicitly partial beyond normalized source geometry and bounded observations.
- [x] Transforms, viewports, gradients, CSS, reuse, clips, and masks distinguish their admitted complete slice from guarded wider semantics.
- [x] Group/root opacity and isolated group compositing have explicit complete behavior on the admitted slice.
- [x] Feature coverage, v1 scope, analysis-status guarantees, and coverage proof obligations agree with the gate inventory.
- [x] The exact M2 milestone checklist item is checked without checking either later M2 gate.
- [x] Structured Report Schema, public MoonBit interfaces, module dependencies, Diagnostics, default behavior, CI, fixtures, and release assets remain unchanged unless a verified defect requires a scoped fix.
- [x] Focused gate validation, relevant MoonBit tests, `moon info`, `moon fmt`, strict native check, and the full native suite pass.
