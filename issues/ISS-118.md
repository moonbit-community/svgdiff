## Description
Implement a complete bounded Compositing and Blending Level 1 slice so a text-only Agent can distinguish blend-mode and isolation changes, identify the foreground and every possibly relevant backdrop change, inspect exact source provenance, and rely on product-rendered regions without confusing categorical modes with one universal numeric parameter.

## Design
Resolve non-inherited `mix-blend-mode` and `isolation` through inline declarations and static author stylesheets, CSS-wide values, and bounded custom-property substitution. SVG 2 does not define presentation attributes for these CSS properties, so same-named XML attributes do not enter the cascade and retain the existing unsupported-attribute Diagnostic. Admit all sixteen standard blend-mode keywords, including `normal`, and `isolation:auto|isolate`. The first complete raster slice is deliberately binary-alpha: explicit-ID, untransformed, integer non-rounded solid rectangles with no stroke or other active effect. Every encountered source and backdrop pixel must therefore have alpha 0 or 255. This admits exact channel formulas and source-over results without claiming unverified continuous-alpha or antialiased-edge behavior.

Render the SVG root as an isolated group. Ordinary `svg`/`g` containers with `isolation:auto`, unit opacity, no own blend mode, and no isolating effect remain group-invariant: their children composite directly into the current group backdrop in stacking order. `isolation:isolate` is complete only on the root SVG or an authored-ID `g`: it creates a transparent initial backdrop, then source-over composites the completed child layer once into the parent. A leaf with non-normal `mix-blend-mode` blends its isolated source pixels with the current group backdrop before source-over. Anonymous or instance isolation hosts, container-level blend modes, opacity/effect interactions, use instances, transforms, fractional alpha/geometry, stroke, curved content, and dynamic declarations remain precise Diagnostics in this item.

Report `compositing.blend_mode` and `compositing.isolation` as categorical Atomic Differences with exact winning facts, computed equivalence, affected foreground/backdrop subjects, measured raster evidence, localized regions, and no invented scalar parameter delta. Backdrop membership is the conservative ordered prefix inside the nearest isolation boundary. Blend/isolation events use comparison-wide Changed Fact candidates until finer compositing provenance is proven, guaranteeing that a simultaneous backdrop change cannot be omitted. Structural stacking comparisons must use the same product compositor so reorderings that alter a blend backdrop remain visible and causal.

Bound project-owned blend work by a fixed count of admitted blend/isolation surfaces and aggregate viewport pixels. Add Chromium source/canonical pairs that cover all blend formulas, transparent versus opaque backdrop behavior, non-isolated group invariance, explicit isolation, stacking order, cascade, and categorical source equivalence. Keep raw `mizchi/svg@0.2.1` observations unchanged and give every divergence an executable `static-blend-compositor@1` disposition.
