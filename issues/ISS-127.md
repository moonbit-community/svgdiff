## Description
Changed-pixel fraction and RGBA error mix geometry, coverage, color, and compositing. Painted-boundary displacement describes where alpha-support edges moved but not how much soft painted coverage changed. A text-only Agent needs a separate symmetric numeric observation that ignores RGB values and retains both absolute affected area and a bounded normalized fraction.

## Design
Add nullable `painted_coverage_difference` to `DifferenceMagnitude`. A measured object uses method ID `symmetric_alpha_coverage_l1_over_union/v1` and records:

- `before_coverage_css_px2 = sum(alpha_before / 255) / dpr^2`;
- `after_coverage_css_px2 = sum(alpha_after / 255) / dpr^2`;
- `absolute_difference_css_px2 = sum(abs(alpha_before - alpha_after) / 255) / dpr^2`;
- `union_coverage_css_px2 = sum(max(alpha_before, alpha_after) / 255) / dpr^2`;
- `fraction = absolute_difference_css_px2 / union_coverage_css_px2`, or measured zero when the union is zero.

All sums use isolated pinned-renderer RGBA8 alpha on equal-sized comparison surfaces. The object is invariant under swapping before and after except that the named per-side coverage values swap. It is `0` for equal alpha coverage and `1` for disjoint or one-empty coverage, independent of RGB color. It remains raster-quantized evidence rather than analytic vector area or subpixel isocontour integration.

Reuse the bounded alignment-level isolated-paint cache introduced for painted-boundary displacement so one before/after render pair supplies both observations. Attach the coverage object to aligned entity Atomic Differences whose two-sided isolated painting is supported, including geometry and solid-paint changes; resource-role, presence, unaligned, unsupported-isolation, dimension-mismatch, and budget-exhausted cases remain null. Several Atomic Differences for one alignment intentionally share one observation. Do not replace boundary, exact parameter, event raster, presence, color, or future perceptual fields.

Advance the module and Structured Report schema because the new required nullable object changes serialized `DifferenceMagnitude`. Archive Schema `1.37` and one canonical report, update compatibility and Agent evidence, and keep renderer identity, conformance profile, ordering policy, Diagnostics, and Impact Assessment unchanged.
