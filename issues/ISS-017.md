## Description
Presence painted coverage currently counts the composited document inside subject bounds, attributing pixels from underlying or overlapping entities to the inserted or deleted subject.

## Design
Reconstruct the aligned presence-side basic subjects from their normalized facts in a minimal SVG under the same fixed profile, render that isolated artifact, and count its nontransparent pixels. Keep final event raster difference as a separate measurement.

## Acceptance Criteria
- [x] A transparent insertion over opaque existing content reports zero painted coverage.
- [x] An opaque duplicate insertion retains nonzero painted coverage while final raster difference remains zero.
- [x] Generic insertion and deletion coverage tests pass.
- [x] Full native validation passes.

## Close Notes
Presence coverage now reconstructs the aligned presence-side basic subjects from normalized facts, XML-escapes them into a minimal same-profile SVG, renders that isolated artifact, and counts only its alpha coverage. This prevents underlying scene pixels from being attributed to a transparent insertion while retaining nonzero coverage for an opaque duplicate whose final raster response is zero. Verified all 69 native tests.
