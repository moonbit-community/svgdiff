## Description
Schema `1.40` reports event-local changed-pixel mean DeltaEOK, but it has no spatial-frequency perceptual map. The roadmap selects LDR-FLIP as the next optional rendered-perception channel and requires every viewing parameter to be recorded rather than inferred from an ambient display.

## Design
Add nullable `ComparisonProfile.flip_viewing_conditions`. A present value contains one finite `pixels_per_degree` value in the supported `[1, 4096]` range, created through an invariant-preserving public constructor. The lower bound prevents a numerically degenerate feature kernel and the upper bound prevents an unbounded filter radius. The default remains absent; no implicit 67 PPD or monitor geometry is introduced. The CLI adds `--flip-pixels-per-degree PPD`.

Add required `RenderedEvidence.perceptual_flip` with explicit computed or not-computed state. `flip_not_requested`, `perceptual_background_absent`, `rendered_evidence_unavailable`, and `perceptual_map_budget_exceeded` remain distinct reasons. A computed map uses method ID `nvlabs_ldr_flip/v1.7-b475eb4b`, records the event-local pixel bounds, and serializes row-major values in `[0,1]` as unsigned 16-bit big-endian samples in padded RFC 4648 base64 with an explicit `1/65535` quantization step.

For each event, form an event-specific test image by replacing only exact raw-different pixels contained by that event's Difference Regions; every other test pixel equals the before image. Composite both reference and event-specific test pixels over the same recorded Perceptual Background in linear sRGB. Evaluate the NVIDIA LDR-FLIP v1.7 color and feature pipelines under the declared pixels per degree. Retain the event bounds expanded by the complete FLIP response radius and use additional surrounding pixels only as convolution context, so unrelated scene changes do not enter the map. An event with zero selected pixels produces an explicit empty computed map.

Keep aggregate output to at most 1,048,576 map pixels and FLIP convolution work to at most 268,435,456 kernel-sample visits per report. Budget exhaustion is event-local not-computed evidence and does not change analysis coverage, raw rendering, Difference Regions, equality, Diagnostics, causes, or ordering. This item exposes the map only; canvas/event means, p95, maximum, threshold area, severity, and Impact Assessment remain separate roadmap items.

Advance the module and Structured Report schema because the profile and every Rendered Evidence object gain required fields. Archive Schema `1.40` and one canonical report, update compatibility and Agent evidence, and keep renderer identity, conformance profile, and ordering policy unchanged. Schema `1.41` and module `0.5.21` are the target identities.
