## Description
Provide and document a local installation workflow that builds the release native executable and makes `svgdiff before.svg after.svg` callable through `PATH`.

## Design
Add a small POSIX installer that invokes the supported MoonBit release build, installs the single native executable as `svgdiff`, defaults to `$HOME/.local/bin`, and accepts an explicit `--bindir`. Do not add binary publishing, checksums, shell completion, package-manager metadata, or cross-platform release automation in this item.

## Acceptance Criteria
- [x] The installer builds `modules/svgdiff/cmd/svgdiff` in native release mode and installs an executable named `svgdiff`.
- [x] The default destination and `--bindir` override are documented.
- [x] The installer reports whether the selected directory is already on `PATH` and gives the exact export command when needed.
- [x] An integration test invokes the installed command from outside the repository and validates its JSON report.
- [x] Reinstalling to the same destination is deterministic and succeeds.
