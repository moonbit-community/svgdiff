## Description

## Design
Treat this as a gate audit, not a second installer implementation. Require the public installation instructions to name the release build, default destination, PATH setup, and direct two-file invocation. Require the integration test to install into an isolated directory, invoke the installed production binary from outside the repository, validate its current report identity and semantics, and prove deterministic reinstall behavior.

- [x] Public documentation gives a complete local installation and PATH procedure.
- [x] The installed command is invoked as `svgdiff before.svg after.svg` outside the repository.
- [x] The installed production binary emits a valid current Structured Report without stderr.
- [x] Help, version, compact JSON, and one-stdin modes remain available after installation.
- [x] Reinstalling the same release binary is deterministic.
