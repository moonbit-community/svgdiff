## Description
Promote the comparison engine from a prototype-only package to the public module and expose a usable native command that compares two SVG files and emits the complete structured report as JSON.

## Design
Keep dependency-specific XML, SVG scene, image, and pixelmatch types private. Expose project-owned report types and a stable schema version. The CLI accepts two paths plus optional viewport dimensions, writes JSON to stdout or a requested file, and uses diagnostics plus exit status for invalid invocation or failed analysis.

## Acceptance Criteria
- [x] The root package exposes the comparison seam using project-owned types.
- [x] CLI integration tests compare fixture files and parse its JSON output.
- [x] Invalid arguments and unreadable inputs fail clearly.
- [x] A checked-in JSON Schema describes the emitted contract.
- [x] README documents supported scope, diagnostics, examples, and non-goals.
- [x] `moon info`, formatting, targeted tests, and native checks pass.
