# ISS-060: Keep raw magnitude evidence authoritative

## Description
Make the current no-Impact-Assessment boundary explicit and prove that domain ordering is derived only from retained raw magnitude components rather than replacing them with hidden or policy-dependent scores.

## Design
Treat `DifferenceMagnitude`, optional `PresenceMagnitude`, and event rendered magnitude as primary observations. Keep `DomainOrdering` as a reproducible same-domain view. Validate every canonical production difference by recomputing its v1 ordering tuple from the serialized raw fields. Document that human labels, future severity labels, and a future Impact Assessment are policy outputs that cannot establish difference identity, equality, or measurement.

## Acceptance Criteria
- [x] Current documentation identifies every authoritative raw magnitude surface and the absence of an Impact Assessment in schema `1.0`.
- [x] Every canonical Atomic Difference retains the complete raw `DifferenceMagnitude` field set with numeric-or-null values.
- [x] Every canonical `v1_domain_lexicographic` tuple is exactly reproducible from retained raw magnitude fields.
- [x] Missing raw measurements remain null and are omitted from derived tuples rather than converted to zero.
- [x] Agent guidance forbids treating ordering components or corpus labels as replacement measurements or cross-domain severity.
- [x] Future Impact Assessment requirements preserve raw observations and identify their policy and calibration corpus.

## Close Notes
Defined the current schema `1.0` boundary: authoritative quantitative evidence consists of the raw `DifferenceMagnitude`, optional `PresenceMagnitude`, and event rendered magnitude surfaces. The report has no Impact Assessment, universal score, or engine severity label. Human annotation tiers and corpus categories remain hidden evaluation data rather than production classifications.

Extended canonical production-report validation to require the complete nine-field raw magnitude vector with numeric-or-null values and to recompute every `v1_domain_lexicographic` tuple from its documented domain-specific source fields. Exact equality proves ordering contains no hidden score; canonical null-heavy cases prove unavailable values are omitted rather than coerced to zero.

Documented mandatory constraints on a future Impact Assessment: additive raw-evidence preservation, opaque policy identity, explicit inputs and calibration artifacts, traceability, and no authority to create or erase differences, establish equality, or override coverage.
