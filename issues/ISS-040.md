## Description
Define and enforce the obligations every analyzer result must satisfy before it may contribute to a complete report.

## Design
Place one proof gate after final report enrichment. Validate matrix shape and statuses, Diagnostic closure, encountered subjects and properties, aligned subjects, Atomic Difference domains, indeterminate and unavailable layer states, and status summarization. Downgrade any incomplete proof through a stable Diagnostic instead of trusting analyzer-local status.

## Acceptance Criteria
- [x] Proof obligations are documented as a current engine contract.
- [x] Every analyzer path passes through one proof gate before returning complete.
- [x] Missing subject, property, or domain rows prevent complete status.
- [x] Limited and failed cells require exact layer-specific Diagnostic justification.
- [x] Complete, partial, and failed production reports satisfy the gate.
- [x] Deliberately incomplete analyzer outputs are downgraded in whitebox tests.
