## Question

How should the report make exact parameter deltas, rendered measurements, zero results, missing measurements, Pareto-frontier membership, and incomparable magnitude dimensions quickly scannable without inventing subtle/major labels or a universal scalar?

## Notes

- 2026-07-18: Accepted five unit-preserving Magnitude Channels: Parameter Change, Spatial Outcome, Canvas Response, Perceptual Observation, and Intrinsic Resource Response. Applicable raw vectors remain separate; measured zero, inapplicable evidence, and unavailable evidence remain distinct. Domain Ordering and Impact Assessment are derived views, not channels.
- 2026-07-18: Accepted policy-bounded ordering. Visual Events expose the report's Impact frontier, exact ties, incomparability, null measurements, and domination witnesses without a second total order. Atomic Differences use Domain Ordering only inside one exact domain and policy identity; empty tuples and cross-domain pairs remain unranked.
- 2026-07-18: Accepted dual-layer numeric formatting: a unit- and denominator-bearing display value with at most four significant digits and scientific notation as needed, plus the copyable raw JSON number. Rounded values use `≈`; nonzero never displays as zero; fractions may add but never replace their raw values.
- 2026-07-18: Accepted explicit Magnitude Availability States: measured, not computed, not requested, not applicable only under a declared rule, and no value reported for an unexplained null. Expected but unavailable channels remain visible with reasons and Diagnostics; measured zero remains numeric evidence.
- 2026-07-18: Accepted an uncalibrated two-dimensional Impact Map plus exact per-Event coordinate and relation text. Frontier points, dominated points, ties, incomparable groups, null measurements, witnesses, policy identity, and calibration status stay explicit; the map is navigation and never replaces the inventory or raw measurements.
- 2026-07-18: Accepted Magnitude Graphics only with explicit absolute scales, units, scopes, and accompanying display values. Fixed-range fractions and unit-bearing distribution plots are allowed; report-relative maximum bars, cross-channel scales, color-only encodings, and zero graphics for unavailable evidence are forbidden.

## Close Notes

Resolved magnitude presentation as five independent, unit-preserving channels with no universal score or severity. Numeric values use a readable, approximation-marked display beside the copyable raw report value and explicit units, scope, denominator, method, and samples where applicable. Measured zero, not computed, not requested, declared inapplicability, and unexplained null remain distinct. Event comparison exposes only the report's uncalibrated Impact Pareto relation through exact coordinates, relation text, and an optional two-axis Impact Map; Atomic Difference ordering remains bounded to one exact domain and policy. Graphics require declared absolute scales and may not invent report-relative severity. Every complete raw vector and availability state remains inspectable.
