## Description
Schema `1.42` preserves a rich raw magnitude vector but leaves every cross-domain main-difference choice to the consumer. A text-only Agent needs a machine-readable, traceable main-event result without inventing a universal scalar, silently comparing domain-specific units, or promoting hidden corpus tiers into product labels.

## Design
Add one required top-level `impact_assessment` produced by versioned policy `event_rendered_pareto/v1`. Visual Events are the candidates because they are the accepted primary reading unit and already preserve every contributing Atomic Difference ID.

The policy uses only two common whole-canvas event measurements: `RenderedMagnitude.changed_pixel_fraction` and `RenderedMagnitude.linear_premultiplied_rgba_rmse`. One measured event dominates another only when both fields are greater than or equal and at least one is strictly greater. The non-dominated events form the main frontier. Exact equal measured vectors form one tie group. Different non-dominated vectors, and every event whose rendered magnitude is unavailable, remain separate incomparable groups. Missing evidence is never converted to zero.

The result records policy identity, complete/partial/not-applicable status, `not_calibrated`, exact input field IDs, candidate count, frontier relation, frontier groups with event and Atomic Difference links plus nullable measured vectors, and one deterministic domination witness for every dominated event. Frontier groups and witnesses use MoonBit `String::compare` shortlex event-ID ordering only for serialization, while each group's Atomic Difference links preserve the report's existing deterministic difference order; neither is an importance tie-break. The policy applies no weights, thresholds, severity labels, visibility decisions, equality decisions, or domain-specific tuple comparison.

This item defines and implements the uncalibrated partial-order baseline. The next roadmap item separately evaluates thresholds and ordering rules on the human-labeled corpus before any `none`/`low`/`medium`/`high`, subtle, salient, or major interpretation can enter production output. Advance the module and Structured Report schema, archive Schema `1.42` and one canonical report, and update compatibility, Agent, corpus, mutation, determinism, and distribution evidence. Schema `1.43` and module `0.5.23` are the target identities.

## Notes
- Exact equality of the two measured inputs is a policy tie, not proof that the events are semantically identical.
- Multiple frontier groups are explicitly incomparable; their serialized order is never a total cross-domain ranking.
- Human annotation tiers and corpus category names remain hidden evaluation data.
