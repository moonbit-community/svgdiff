## Close Notes
Accepted ADR 0038: do not implement exact per-pixel Contribution Index propagation in the current roadmap sequence. Cause Envelope containment and quantitative contribution weights answer different questions; the current product requires sound possible-cause recall, not exact allocation through every compositing operation.

The decision cites current evidence without overstating it: thirty-six complete directional mutation comparisons and 130 regions retain the declared actual fact, every eligible human-labeled case has complete causal recall, the seven-case baseline has five unique-per-case candidates, six candidate occurrences, five regions, and zero labeled false-positive fraction, and only the deterministic report-only evidence adapter—not an external language model—has passed the Agent thresholds.

Recorded renderer ownership and semantic complexity plus four reopen triggers: a minimized Agent-task ambiguity after safe pruning, a versioned precision threshold failure, a product requirement for quantitative weights, or a stable dependency contribution API with favorable ownership cost. Clarified that ADR 0038 supersedes only ADR 0006's exact Contribution Index clause. The deferred implementation checklist remains visible and unchecked.

Verified generated interfaces and formatting, warning-clean native checks, all 103 MoonBit tests, forty directional mutation reports and causal property, evaluation volume and precision metrics, reproducible benchmark pass/fail behavior, report determinism and causal controls, local Markdown links, and `git diff --check`.
