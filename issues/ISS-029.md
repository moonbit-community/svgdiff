## Description
Record independently authored actual-cause ground truth for curated cases that are suitable for testing Cause Envelope recall.

## Design
Use semantic fact locators rather than copying unstable report IDs. Admit only cases with a controlled edit, a rendered Difference Region, and enough supported semantics to state the actual changed cause. Explicitly exclude computed-equivalent, zero-contribution, and unsupported cases. Keep conservative envelope candidates distinct from actual-cause labels so false positives remain measurable later.

## Acceptance Criteria
- [x] Every curated case declares whether it is eligible for Cause Envelope recall evaluation.
- [x] Eligible cases identify reference regions and at least one semantic actual-cause locator.
- [x] Fact locators record property, affected subjects, and authored values when available.
- [x] Resource-mediated ground truth distinguishes the edited resource fact from conservative downstream candidates.
- [x] An automated check validates corpus coverage, region references, locator structure, and exclusion reasons.
