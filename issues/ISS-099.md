# ISS-099: Complete ordinary inheritance for supported visual properties

## Description
The source hierarchy already resolves inherited declarations and preserves their owners, origins, Source Spans, and affected leaf subjects. However, the inheritance-specific report path is permanently partial: it does not feed effective inherited values into leaf used-value analysis and it defers every rendered measurement. Complete the ordinary-inheritance slice without collapsing ancestor declarations into false leaf-local changes.

## Design
Keep the source hierarchy as the authority for declaration ownership and fan-out. Supply its effective inherited declarations to the existing leaf subject analysis before geometry, stroke, and marker used values are computed. The inheritance report then reuses the same computed-relation and magnitude logic as the generic shape report while retaining owner-level Changed Facts and Source Resolution Pairs.

Add a private renderer normalizer after cascade materialization that writes the admitted effective inherited values onto supported rendered leaves. This compensates for the pinned renderer's narrower inherited-style stack while preserving original report provenance. Unsupported CSS-wide keywords, custom properties, `currentColor`, paint servers, marker-content paint, and independently guarded renderer behavior remain outside this item.

- [x] Presentation attributes, inline declarations, and matched stylesheet declarations all participate before inheritance.

- [x] Source Resolution Pairs retain resolution kind, declaration owner, inheritance depth, origin, authored value, and exact Source Span.
- [x] One changed ancestor declaration identifies every affected supported rendered leaf, with no marker-resource child falsely treated as a scene entity.
