## Description
Measure parse and admission, subject alignment, raster rendering, pixel-region extraction, Cause Envelope provenance, and report serialization as distinct production-stage microbenchmarks.

## Design
Use MoonBit's native release benchmark harness and call package-private production functions from a whitebox benchmark file. Build deterministic fixture inputs and every stage prerequisite outside the timed closure so a result names only the intended work. Retain six stable stage IDs and produce a machine-readable, versioned artifact through one repository command.

These microbenchmarks diagnose where time is spent; their stages may overlap with the end-to-end pipeline and must not be summed into total comparison latency. Do not add pass/fail latency or memory thresholds in this item. Representative small, medium, and large workloads plus performance budgets remain the next roadmap item.

## Acceptance Criteria
- [x] Native release benchmarks cover parse/admission, alignment, rendering, region extraction, provenance, and serialization with stable stage IDs.
- [x] Every timed closure calls production code and excludes fixture or prerequisite construction.
- [x] One command writes a versioned machine-readable artifact containing all six stage summaries and workload metadata.
- [x] Validation rejects missing, duplicate, nonpositive, or malformed stage statistics without asserting machine-specific timing thresholds.
- [x] Documentation distinguishes pipeline microbenchmarks from the Agent-quality benchmark and forbids summing overlapping stage measurements.
- [x] Current CI sanity coverage, documentation maps, and roadmap status include the new suite.
