## Description
Measure the pinned `mizchi/svg@0.2.1` renderer against the deterministic Chromium oracle without changing production comparison semantics.

## Design
Render each conformance fixture through the pinned renderer, decode the matching browser PNG, normalize both images to premultiplied RGBA8, and record deterministic per-case error metrics. Classify fixtures by geometry, paint, alpha, clipping, and compositing, and distinguish complete-eligible support fixtures from exploratory fixtures outside the current coverage claim.

## Acceptance Criteria
- [x] Fixed fixtures exercise geometry, paint, alpha, clipping, and compositing.
- [x] Pinned-renderer and Chromium pixels are compared in premultiplied RGBA8.
- [x] A deterministic report records changed pixels, changed fraction, RMSE, and maximum channel delta per case.
- [x] The report distinguishes supported and exploratory coverage claims.
- [x] A committed baseline makes renderer drift observable without accepting divergences.
- [x] Production engine APIs and Structured Report semantics remain unchanged.
