# ISS-109: Build the unified resource dependency graph

## Description
Replace the admission-only boolean reference graph with one private, typed source-level dependency graph for every admitted or guarded resource family. Preserve the report boundary: project semantic passes may query the graph, while Structured Report JSON continues to project only difference-relevant Changed Facts, affected subjects, and Diagnostics.

## Design
Build the graph once from the bounded namespace-aware XML event stream. Give every dependency-bearing source element a deterministic source subject and preserve exact kind, optional authored ID, source offset, and definition span. Merge duplicate authored IDs conservatively for lookup without erasing their individual source nodes.

Represent each authored reference as a typed edge with its source subject, containing definition scopes, relation kind, locator class, decoded local target when present, and exact attribute Source Span. Distinguish template inheritance, paint, marker attachment, clipping, masking, filtering, use or symbol instancing, image input, and otherwise unsupported resource syntax. Retain local, missing, external, data-URI, and invalid states without fetching or decoding anything.

Provide deterministic direct and transitive forward and reverse queries. Ancestor definition scopes inherit descendant dependencies so a cloned symbol or referenced effect cannot hide a nested resource path. Reverse traversal is conservative and may include duplicate-ID alternatives, but it must contain every source-level consumer reachable through the accepted static grammar.

Make cycle detection, transitive use-expansion accounting, and the fixed graph-edge budget consume this graph rather than a second admission-only representation. Existing gradient, pattern, marker, and use semantic passes may keep their value-specific documents, but resource target and reachability decisions must agree with the unified graph. Unsupported clip, mask, filter, symbol-overflow, and image semantics remain partial through existing located Diagnostics; this item does not implement their pixels, external bundles, or resource policy.
