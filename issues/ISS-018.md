## Description
Resolve closure-review cases involving false leaf localization for container opacity, missing root SVG opacity source differences, and ignored gradient semantics beyond the first stop.

## Design
Never resolve container alignment references through the leaf-only subject inventory, extend opacity source extraction to both `svg` and `g`, and compare a canonical signature of all gradient semantics outside the analyzer's supported first stop color.

- [x] Changes to later gradient stops or unsupported gradient attributes reduce coverage.
- [x] Full native and CLI validation pass.
