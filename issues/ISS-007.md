## Description
Replace first-rect and fixture-specific comparison paths with one generic analyzer for every aligned subject in the supported deterministic static subset.

## Design
Initially support `svg`, `g`, `rect`, `circle`, `ellipse`, `line`, `polyline`, and `polygon`, with normalized geometry, fill, stroke, stroke width, and opacity facts plus ordinary inheritance. Enumerate every changed supported fact. Unsupported elements, attributes, CSS, resources, or effects reduce coverage rather than being treated as equal.

## Acceptance Criteria
- [ ] Every changed supported fact on every aligned subject is reported exactly once.
- [ ] Basic shapes beyond `rect` are compared through the same engine.
- [ ] Formatting variations and ID/order-only changes remain non-differences.
- [ ] Unsupported semantics produce subject-local Diagnostics and `partial` coverage.
- [ ] Targeted tests and native checks pass.
