## Description
Replace first-rect and fixture-specific comparison paths with one generic analyzer for every aligned subject in the supported deterministic static subset.

## Design
Initially support `svg`, `g`, `rect`, `circle`, `ellipse`, `line`, `polyline`, and `polygon`, with normalized geometry, fill, stroke, stroke width, and opacity facts plus ordinary inheritance. Enumerate every changed supported fact. Unsupported elements, attributes, CSS, resources, or effects reduce coverage rather than being treated as equal.

## Acceptance Criteria
- [x] Every changed supported fact on every aligned subject is reported exactly once.
- [x] Basic shapes beyond `rect` are compared through the same engine.
- [x] Formatting variations and ID/order-only changes remain non-differences.
- [x] Unsupported semantics produce subject-local Diagnostics and `partial` coverage.
- [x] Targeted tests and native checks pass.

## Close Notes
Implemented one aligned-subject analyzer for rect, circle, ellipse, line, polyline, and polygon facts; expanded inherited fill to all supported entity kinds; normalized presentation attributes and inline styles into the same fact model; and attached entity Atomic Differences to Subject Alignments. Unknown elements and visual attributes reduce coverage. Verified with six generic-shape tests, alignment tests, warning checks, and the full 39-test native suite.

Review follow-up: generalized ordinary inherited visual facts from fill-only handling to fill, stroke, stroke width, and opacity, including ancestor Changed Fact propagation and resolved provenance per affected entity. Incomplete inline declarations now force the existing CSS coverage diagnostic path. Added failing regressions for inherited stroke and unsupported inline declarations, then verified all 57 native tests.

Second review follow-up: corrected the model so only fill, stroke, and stroke width inherit; local entity opacity remains reportable, while opacity on `svg`/`g` produces an explicit unsupported group-compositing Diagnostic. Preflight now diagnoses unsupported special paint values and missing paint-server references without rejecting supported declared gradients. Verified all 65 native tests.
