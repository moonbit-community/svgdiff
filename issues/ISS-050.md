## Description
Add focused SVG pairs that fail if the engine returns false complete, treats an unsupported change as equality, aligns by source order, leaks unrelated causes across regions, or orders same-domain differences by the wrong magnitude.

## Design
Keep the adversarial suite separate from the human-labeled curated corpus. A versioned manifest names one failure mode per pair. A validator runs the production CLI and checks the exact safety invariant for each mode rather than relying only on snapshots or minimum difference counts.

## Acceptance Criteria
- [x] An unchanged unsupported feature cannot produce `complete`.
- [x] A changed unsupported feature with no Atomic Difference cannot become equality.
- [x] Reordering unlabelled subjects preserves visual correspondence instead of source-order alignment.
- [x] Disjoint outcome regions do not acquire unrelated Changed Fact candidates.
- [x] Same-domain geometry differences are ordered by descending magnitude.
- [x] The manifest and validator are deterministic and versioned.
- [x] Documentation distinguishes adversarial safety cases from human-labeled evaluation cases.

## Close Notes
Added five focused adversarial SVG pairs, a versioned manifest, a production-CLI validator, deterministic fixture/report hashing, and a double-run shell gate. The suite proves unchanged transforms remain partial, unsupported path changes with empty difference lists cannot establish equality, unlabelled reordered rectangles align across source indices, disjoint paint regions retain only event-local causes, and geometry magnitudes `4` and `1` are emitted in descending policy order.

The adversarial suite remains separate from the curated human-label and agent-benchmark corpus. Documentation states that these cases enforce named engine invariants and do not enter human-label aggregates without separate annotation.
