## Description
Implement the accepted self-contained HTML artifact after the core JSON contract is stable. The report presents both original SVGs on the left and categorized, ordered diff items on the right; hovering or selecting an item localizes its Difference Regions on both views. The full JSON report remains inspectable.

## Design
Generate one offline HTML file with escaped original SVG source, embedded structured JSON, CSS, and vanilla JavaScript. The HTML is a presentation over the report and must not recompute semantic differences.

## Acceptance Criteria
- [x] The report embeds both SVG inputs without executing scripts or fetching network resources.
- [x] Diff items are grouped by domain and ordered by the report's Domain Ordering.
- [x] Hover and selection highlight every associated Difference Region in both SVG views.
- [x] Every item can be checked and the complete JSON can be expanded.
- [x] Snapshot and structural tests cover escaping and report bindings.
