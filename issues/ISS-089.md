## Description
The strict path IR from ISS-088 is retained only as alignment evidence. A changed `d` attribute therefore still produces no Atomic Difference, exact parameter magnitude, or path-specific geometric displacement for a text-only agent, even though the engine can parse both sides completely.

## Design
Compare one-to-one aligned paths segment by segment. Emit one Atomic Difference for every changed normalized segment parameter or topology position, while treating relative, shorthand, and other command-spelling changes with identical normalized geometry as computed-equivalent source differences. Use exact normalized parameter values and signed deltas under the current identity-coordinate slice. Improve path alignment cost with normalized segment parameters instead of segment count alone.

Render each aligned path in isolation from its retained supported declarations under the Comparison Profile, extract alpha boundary pixels, and retain the symmetric maximum nearest-boundary displacement in the existing `geometry_displacement_css_px` magnitude field. Measured zero remains numeric zero; an empty boundary on only one side remains unavailable. This is a guarded pinned-renderer observation, not accepted path renderer conformance. The existing `unsupported_visual_subject` Diagnostic continues to limit path Computed Appearance and Rendered Evidence until transforms, complete stroke geometry, paint semantics, and path renderer conformance are implemented. Mean, p95, and maximum displacement distributions remain owned by the separate Phase 5 roadmap item.

## Acceptance Criteria
- [x] One-to-one aligned valid paths enumerate every changed normalized segment parameter and every segment-kind, insertion, or deletion difference deterministically.
- [x] Relative, shorthand, horizontal/vertical, compact, and numeric-spelling variants with equal normalized geometry are distinguished from real geometric changes without reporting whitespace-only changes.
- [x] Numeric path parameter differences retain exact signed and absolute values independently of raster quantization.
- [x] Path alignment cost uses normalized segment kinds and values rather than only segment counts.
- [x] Isolated alpha boundaries produce a symmetric maximum CSS-pixel displacement, including measured zero and explicit unavailability when only one boundary exists.
- [x] Path findings remain partial behind the existing coverage guard and do not claim transform, stroke, paint, or renderer completeness.
- [x] Current contracts, canonical examples, Agent evaluation fixtures, and version identities describe the implemented boundary.
- [x] Relevant MoonBit and repository validation gates pass.
