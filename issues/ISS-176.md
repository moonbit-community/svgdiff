## Question

Which factual, orthogonal classification axes should organize Visual Events and their Atomic Differences so that semantic domain, computed relation, rendered outcome, and evidence availability remain distinct, and which axis should control the default grouping?

## Notes

- 2026-07-18: Accepted three orthogonal Review Classification Axes: rendered-outcome state on Visual Events, Computed Relation on Atomic Differences, and Difference Domain on Atomic Differences. Magnitude and Impact are not classification axes.
- 2026-07-18: Accepted the default Rendered Outcome Groups and order: measured nonzero, not computed, then measured zero. Report-level analysis status stays global; no group implies visibility, severity, importance, or equality.
- 2026-07-18: Accepted Event Relation Summary counts, contains-relation filtering, and exact child-level Computed Relations. Computed Relation does not create secondary Event groups.
- 2026-07-18: Accepted two-level domain presentation: event-level Domain Family sets for scanning and contains-family filtering, plus the exact domain on every Atomic Difference. The initial families are Presence, Geometry, Paint, Compositing, Resource, Text, and Structure; unknown domains remain explicit rather than entering `Other`.
- 2026-07-18: Accepted a separate Evidence Availability Summary containing declared child evidence-layer counts, exact rendered-outcome status, and linked Diagnostic count. It does not create an Event coverage class, completeness ratio, confidence score, or additional grouping axis.

## Close Notes

Resolved the HTML review classification as three orthogonal factual axes. Visual Events use ordered Rendered Outcome Groups: measured nonzero, not computed, then measured zero. Atomic Difference Computed Relations remain exact child facts and appear at Event level only as counts and `contains` filters. Domain Families provide review-facing labels and filters while every child retains its exact domain; unknown domains remain explicit. Evidence availability is shown separately through raw layer counts, rendered status, and Diagnostic count. Magnitude, Impact, visibility, severity, importance, equality, report-level analysis status, and Event completeness are not classification axes.
