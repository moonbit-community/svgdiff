## Description
Add successful `--help` and `--version` command modes and expose the consumer-visible schema, engine, renderer, and ordering-policy versions.

## Design
Handle informational flags before positional argument parsing so they never require SVG paths and exit successfully. Keep the output deterministic and human-readable. Use the module version from `moon.mod`, the current schema constant, the production renderer identity, and the domain-ordering policy already fixed by the report contract.

## Acceptance Criteria
- [x] `svgdiff --help` exits zero and documents every current option and exit status.
- [x] `svgdiff --version` exits zero without input files.
- [x] Version output includes CLI/module, schema, engine, renderer, and ordering-policy identities.
- [x] Existing invalid-argument behavior remains status `2`.
- [x] Unit and installed-binary integration tests cover both informational modes.
