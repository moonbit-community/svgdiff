## Description
Complete the exact scalar-parameter magnitude surface promised by Phase 5. Preserve canonical local-user-unit deltas independently from exact device-space parameter displacement, viewport normalization, and entity-relative normalization so a text-only Agent can distinguish a tiny authored change from its coordinate-scaled visual size without relying on raster quantization.

## Design
Retain `parameter_abs_user_units`, `parameter_signed_user_units`, and `symmetric_relative` as the canonical scalar delta in the parameter's admitted local numeric space. Exact authored spelling and units remain in `source_fact_before` and `source_fact_after`; equivalent spellings such as `1in` and `96px` continue to produce zero canonical parameter displacement without losing source provenance.

Add nullable `parameter_abs_css_px`, `parameter_viewport_fraction`, and `parameter_entity_fraction` to `DifferenceMagnitude`. The CSS value is the absolute displacement of the changed scalar parameter after one admitted cumulative coordinate mapping shared by both sides, not a maximum over conflicting mappings or a sampled painted-boundary distance. The viewport fraction divides it by the Comparison Viewport diagonal. The entity fraction divides it by the maximum nonzero diagonal of the before and after conservative painted bounds, considered separately so movement does not inflate its own denominator. Non-scaling stroke scalars use the identity mapping; ordinary stroke scalars require an isotropic linear mapping because an anisotropic transform has no direction-independent scalar conversion. A missing/incomplete or conflicting transform, non-spatial number, zero-size entity, resource shared across contextual consumers, or parameter without one honest scalar mapping remains null rather than zero.

Populate the new surface for admitted scalar entity geometry: basic-shape coordinates/dimensions/radii, image placement/size, scalar stroke lengths, normalized path coordinate/radius parameters with complete transforms, and decomposed transform translation. Preserve `geometry_displacement_css_px` and `geometry_viewport_fraction` as outcome-oriented geometry evidence: stroke boundary movement and path raster-boundary observation are not renamed or substituted for exact parameter displacement. Angle, scale, categorical, list, topology, color, opaque-source, and residual-matrix changes retain their existing typed or nonnumeric evidence.

Use a public `compare`/Structured Report tracer case with a non-identity transform and fixed entity bounds to prove all four scales from independent literals. Add zero-size and unavailable-context controls. Extend canonical examples and Agent guidance so consumers do not confuse parameter CSS displacement, painted-boundary displacement, renderer pixels, or Impact Assessment.

Advance the module and Structured Report schema because new required nullable magnitude fields change the serialized contract. Archive the previous schema and canonical example, update compatibility policy, and keep ordering policy, renderer identity, and conformance profile unchanged unless their meanings actually change.

## Close Notes

Added required nullable CSS-pixel, viewport-diagonal, and entity-relative parameter fields while preserving canonical signed/absolute local deltas, symmetric-relative evidence, and authored source facts. Contextual values require one complete mapping shared by both sides: directed geometry compares basis vectors, undirected radii compare the full linear part, non-scaling stroke scalars use identity, and ordinary stroke scalars require the same isotropic scale. Conflicting or incomplete mappings, anisotropic stroke scalars, non-spatial values, zero or unavailable bounds, and shared resource parameters remain null.

Kept parameter evidence independent from geometry and raster outcomes. Stroke width retains its separately defined maximum painted-boundary movement even when an anisotropic transform makes its CSS parameter scalar unavailable; embedded-image placement no longer substitutes parameter displacement for an unmeasured fitting outcome; path coordinates and radii retain exact scales while angular arc parameters remain non-spatial. Per-side conservative painted-bound diagonals provide the symmetric entity denominator without movement inflation.

Recorded ADR 0081, module `0.5.16`, Structured Report schema `1.36`, archived schema/example/manifest `1.35`, and compatibility migration. All 40 current production examples validate deterministically; compatibility accepts 43 and rejects 4 cases. Verified 558 MoonBit tests, 59 mutation cases, 13 adversarial modes, 24 fuzz cases, 13 Agent tasks, report and cross-platform determinism, CLI/install/completion/module/release/HTML workflows, renderer disposition/conformance/browser/alternate-scale gates, stage benchmarks, and end-to-end performance budgets. Renderer identity, conformance profile `/25`, and v2 ordering tuples remain unchanged.
