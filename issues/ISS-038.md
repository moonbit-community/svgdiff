## Description
Add a compact JSON mode for text-only agent consumers without removing canonical evidence or creating a second incompatible report model.

## Design
Add `--agent-json` and a public compact serializer that emit the complete schema `1.0` report without indentation or line breaks. Keep default JSON unchanged. Prove parsed equivalence in integration tests and record why lossy projection is outside this item.

## Acceptance Criteria
- [x] `--agent-json` emits a one-line schema `1.0` Structured Report.
- [x] Compact and default JSON parse to the same object with every canonical report section retained.
- [x] Default JSON, output-file selection, exit statuses, and HTML behavior remain unchanged.
- [x] The public MoonBit API exposes compact serialization without a new report type.
- [x] Unit, CLI, and installed-binary tests cover the compact mode.
