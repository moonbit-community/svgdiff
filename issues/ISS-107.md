## Description
Model SVG structural containers and same-document `<use>` rendering instances without conflating authored definition nodes with the placed instances that render from them. Reuse the existing cascade, inheritance, geometry, transform, viewport, alignment, provenance, and reference-safety seams so a definition change can remain source-owned while reaching every affected instance outcome.

## Design
Introduce one bounded authored structure index over `svg`, `g`, `defs`, `symbol`, `use`, supported graphics elements, and already admitted resource containers. Every node receives a stable source identity from its nonempty authored `id` or a deterministic generated identity. Record source parent/child relationships and whether the node is directly renderable, a never-rendered definition, a structural container, or a placed use host.

Keep definition identity and instance identity separate. A direct graphics element has no use-instance context. A graphics element cloned through `<use>` retains its corresponding source-definition identity and Source Spans while receiving a deterministic outer-to-inner use-host path that uniquely identifies the placed instance. Public subject references expose this context without rewriting `authored_id`; owner-level Changed Facts remain attached to the actual authored declaration, and affected-subject IDs identify every placed direct or cloned outcome.

Admit acyclic same-document local-fragment `<use>` references to supported graphics elements, `g`, `svg`, `symbol`, or another admitted `use`. Descendants of `defs` and source `symbol` elements never become direct rendered entities, but remain source definitions and may produce cloned instances. Treat the generated use shadow content as children of the use host for ordinary inheritance. Preserve declaration and stylesheet matching from the corresponding source nodes.

Resolve admitted unitless or already-supported length `x` and `y` as the SVG 2 supplemental use translation after the authored `transform`. Apply `width` and `height` only when the direct target is `svg` or `symbol`, using the existing viewport/viewBox and `preserveAspectRatio` machinery. Compose nested use paths, group transforms, instance transforms, and target viewports deterministically.

Retain the existing pre-render cycle and expansion limits. Missing, external, wrong-kind, malformed, unsupported-content, unsupported-length, and otherwise unresolved use instances receive source-located Diagnostics and cannot produce false complete equality. Scripts, animation, events, external documents, interactive shadow DOM, conditional processing, symbol overflow clipping, arbitrary SVG content, structural reordering/stacking differences, and the general cross-resource dependency graph remain outside this item.

Do not classify all structural edits in this item. The next roadmap item remains responsible for structural changes that alter stacking, inheritance, or resource resolution beyond the instance outcomes created here. The following resource-graph item remains responsible for one unified graph across gradients, patterns, markers, clips, masks, filters, symbols, and images.

## Notes
- The normative source is SVG 2 Document Structure and the rendering-tree definition: `defs` and source `symbol` are never rendered directly; `use` creates a rendering-tree instance linked to the corresponding source subtree.
- The accepted identity is a pair of source-definition identity and placement path, not a cloned authored ID and not an XML text-expansion offset.
- Existing cycle and transitive expansion admission remains authoritative and must be reused rather than reimplemented.
