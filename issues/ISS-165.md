## Description
Validate the exact M3 milestone claim that compact Agent-facing summaries link losslessly to the complete evidence graph. Compose the already accepted compact canonical JSON, reconstructable Agent projection, Impact frontier semantic edges, report-reference closure, and derived Markdown presentation boundaries into one versioned gate with explicit negative controls.

“Lossless” applies to canonical compact JSON and projection reconstruction. The optional Markdown summary remains derived orientation: it must preserve stable traceability IDs and direct consumers to the canonical report, but it is not a second complete evidence serialization.

## Design constraints
- Keep ordinary Structured Report JSON authoritative.
- Require compact canonical JSON to parse to the same JSON value as default output.
- Require every accepted projection stream to reconstruct the exact canonical report and reject truncation, duplication, reorder, miscount, relabeling, unknown projection identity, and source-Schema mismatch.
- Require every Impact frontier group to retain the exact ordered union of Atomic Differences owned by its events.
- Require transitive reference closure from frontier events through Atomic Differences, Difference Regions, Cause Envelopes, Changed Facts, Subject Alignments, and Diagnostics.
- Require Markdown summaries to identify the canonical report as authoritative, retain stable event/difference/Diagnostic references, preserve raw availability and Impact ambiguity, and avoid severity, visibility, equality, total-order, or unique-cause authority.
- Do not claim that Markdown alone reconstructs every report field.
- Do not change product code, public APIs, report/projection Schemas, policy identities, CLI behavior, fixtures, labels, thresholds, dependencies, default CI, or release assets unless a verified defect requires a separate scoped fix.

## Acceptance Criteria
- [x] A versioned gate manifest names every required authority, contract identity, obligation, command, and expected negative control.
- [x] Default and compact canonical JSON parse to identical values on the accepted determinism corpus.
- [x] Agent projection reconstruction passes complete, partial, failed, empty-inventory, and FLIP cases and rejects every accepted corruption class.
- [x] Impact frontier event-to-difference semantic edges and transitive report-reference closure pass production reports and their negative controls.
- [x] Derived Markdown summaries retain traceability and authority disclaimers without being represented as lossless evidence serialization.
- [x] A gate validator rejects missing obligations, commands, negative controls, or mismatched contract identities.
- [x] Current Agent JSON, projection, summary, Impact, core-model, documentation-index, dependency/security, and roadmap documents describe the M3 gate accurately.
- [x] The exact M3 compact-summary checklist item is checked only after the composed gate passes; the calibrated-Impact and terminal gates remain unchecked.
- [x] Product code, public interfaces, report/projection Schemas, policy identities, CLI behavior, fixtures, labels, thresholds, dependencies, default CI, and release assets remain unchanged unless a verified defect requires a separate fix.
- [x] Focused gate tests, existing component tests, `moon info`, `moon fmt`, strict native check, full native tests, and `git diff --check` pass.
