## Description
The production report currently recognizes one fixed linear-gradient/rectangle fixture and compares only its first stop color and opacity. Replace that fixture path with deterministic static computed-gradient semantics for every supported entity that uses a same-document linear or radial gradient.

## Design
Parse authored gradient resources independently from entity alignment, retain exact attribute and stop declaration facts, and resolve each resource through a bounded same-document `href`/`xlink:href` template chain. Missing attributes come from the nearest valid template before initial values; direct stop children win as a set, otherwise the nearest referenced gradient with non-descriptive child content supplies the cloned stops. Resolve cloned stop CSS against the referencing gradient host so inherited `color`, custom properties, `currentColor`, and the existing author cascade remain provenance-preserving.

Canonical computed gradients record kind, units, spread method, transform matrix, geometry parameters, and every normalized stop offset/color/alpha. Offsets accept number or percentage syntax, clamp to `[0,1]`, and monotonically raise later regressions to the preceding used offset. Linear defaults are `0%,0%,100%,0%`; radial defaults are `50%,50%,50%`, `fx/fy` default to the resolved `cx/cy`, and `fr` defaults to zero. Resolve `objectBoundingBox` gradients per consuming entity and `userSpaceOnUse` gradients in that entity's current viewport/user space, then compose `gradientTransform` in the specified order. Zero-stop, one-stop, degenerate linear, invalid radius/focal-circle, and equal-offset behavior must remain explicit computed evidence.

Emit resource Atomic Differences for changed template selection, kind, attributes, transform, and individual stop insertions/deletions/offsets/colors/opacities. Emit downstream fill or stroke differences for every affected entity, including cases where the authored paint URL is unchanged. Equivalent authored rewrites remain Source Semantics differences with equal computed-gradient signatures. Unreferenced resource changes remain resource differences with no invented entity outcome.

The current comparison profile admits static same-document references only and fixes ordinary gradient interpolation to sRGB. External resource bundles, missing-paint-server fallback lists, animation/script effects, patterns, and non-default `color-interpolation` remain their separately scheduled boundaries and must retain precise coverage Diagnostics.

## Acceptance Criteria
- [x] Linear and radial gradients resolve all specified/default geometry attributes, `gradientUnits`, `spreadMethod`, and `gradientTransform` into deterministic canonical values.
- [x] Every direct or template-derived stop resolves its number/percentage offset, monotonic used offset, canonical stop color, stop opacity, and effective alpha with exact source provenance.
- [x] Valid same-document `href` and deprecated `xlink:href` chains resolve attributes and stop child sets recursively, honor unqualified `href` precedence, support cross-kind templates, and remain bounded by existing cycle/resource limits.
- [x] Template-derived stop content inherits through the referencing gradient host without rewriting the cloned declaration's origin or Source Span.
- [x] `objectBoundingBox` and `userSpaceOnUse` coordinates resolve per consuming supported entity, including viewport-relative lengths, non-square bounding boxes, cumulative entity transforms, and gradient transforms.
- [x] `pad`, `reflect`, and `repeat`; zero/one/multiple/equal/reversed offsets; degenerate linear vectors; and radial focal-circle edge cases produce explicit computed semantics rather than a broad unsupported guard.
- [x] Resource differences enumerate every changed gradient field and stop operation, while each affected fill/stroke entity receives a mediated computed paint outcome; equivalent rewrites and unreferenced resources are classified correctly.
- [x] Invalid gradient syntax, invalid template targets, unavailable target bounds, external references, non-static content, and deferred color-interpolation behavior emit precise located Diagnostics rather than silently claiming equality.
- [x] The private renderer path either materializes the canonical supported gradient or retains a measured renderer-specific guard without altering authored evidence.
- [x] Focused MoonBit, mutation, canonical report, and Chromium conformance cases cover both gradient kinds, all coordinate modes, transforms, spread methods, template inheritance, stop normalization, equivalence, and guarded boundaries.
- [x] Current contracts, research, an ADR, feature coverage, compatibility/version identities, and the roadmap describe the admitted gradient scope and remaining paint/resource boundaries.
- [x] Relevant MoonBit and repository validation gates pass.
