# ISS-100: Resolve CSS-wide values, currentColor, and custom properties

## Description
The admitted author cascade and ordinary-inheritance model currently stop when a winning declaration contains `inherit`, `initial`, `unset`, `revert`, `currentColor`, or `var()`. These values can change the computed value without changing the consuming declaration and can introduce dependencies on a parent, the inherited `color` property, or a cascaded custom-property declaration. Resolve those dependencies for every currently supported SVG value without treating the substituted value as authored source.

## Design
Add one private computed-style seam after cascade selection and before property-specific used-value parsing. It keeps the winning declaration unchanged, resolves CSS-wide defaulting, computes inherited custom properties per element, substitutes bounded `var()` references and fallbacks with cycle detection, and then resolves `currentColor` from the same element's computed `color`. Property analyzers and the renderer adapter consume the resulting value; Changed Facts and Source Resolution records continue to point to original declarations and Source Spans.

Within the current deterministic author-only profile, `revert` removes all author-origin declarations for that property. Because no user or user-agent declarations are admitted, the result follows ordinary defaulting: inheritance for inherited properties and the documented initial value otherwise. `revert-layer` remains guarded because cascade layers are not implemented. The inherited `color` dependency uses deterministic sRGB black as the profile initial value. Custom-property names remain case-sensitive; their values inherit by default, resolve variables before inheritance, support nested references and fallbacks, and become guaranteed-invalid on missing references without fallback, cycles, malformed admitted syntax, or expansion-budget excess. A consuming invalid-at-computed-value declaration behaves as `unset`.

The admitted variable grammar is the existing deterministic declaration-list scope plus balanced `var()` functions, nested fallbacks, and arbitrary non-string component text. CSS escapes, comments, strings, registered custom properties, animation taint, environment-dependent system colors, cascade layers, and non-author origins remain explicit guards rather than approximations.

## Acceptance Criteria
- [x] `initial`, `inherit`, and `unset` resolve after cascade for every supported inherited and non-inherited property, including root behavior and explicit local provenance.
- [x] Author-origin `revert` removes presentation, stylesheet, and inline author declarations before ordinary defaulting; `revert-layer` remains guarded.
- [x] The inherited `color` property has a deterministic black profile initial value and `currentColor` resolves supported fill, stroke, and currently admitted color consumers from the same element's computed color.
- [x] Custom properties participate in inline and stylesheet cascade applicability, remain case-sensitive, inherit their computed values, and retain original declaration ownership and Source Spans; SVG presentation attributes may consume them but do not define custom properties.
- [x] `var()` supports nested references and fallbacks, including CSS-wide fallback results, without rewriting the consuming declaration's authored or declared value.
- [x] Missing variables, cycles, invalid substituted property values, malformed admitted variable syntax, and expansion-budget excess follow documented invalid-at-computed-value behavior without false complete equality.
- [x] A changed `color` or custom-property declaration identifies every supported leaf whose computed appearance depends on it, while unused dependency changes do not claim a visual outcome.
- [x] Effective computed values reach geometry, fill, stroke, stroke geometry, opacity, vector effect, marker attachment, and admitted resource-color analysis where those values are currently supported.
- [x] The renderer adapter materializes only complete resolved values on private renderer-input copies and leaves independently unsupported syntax guarded.
- [x] Focused MoonBit, mutation, canonical report, and Chromium conformance cases cover CSS-wide keywords, currentColor, variable cascade/inheritance, nested fallback, cycles, invalid substitution, and provenance moves.
- [x] Current contracts, an ADR, feature coverage, evaluation artifacts, compatibility/version identities, and the roadmap describe the admitted computed-value scope and remaining CSS boundary.
- [x] Relevant MoonBit and repository validation gates pass.
