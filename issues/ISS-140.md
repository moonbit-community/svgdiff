## Description
The Phase 7 roadmap requires evidence that a text-only Agent can answer what changed, how much, where, and why from the Structured Report alone. The report-only harness and answer schema already carry exact magnitude claims, but `svgdiff-evaluation-metrics/1` currently ignores those claims. A structurally valid answer can therefore invent, alter, or omit measurements without affecting the benchmark gate.

Add independent magnitude-fidelity scoring against the canonical Atomic Difference evidence. Keep every dimension separate: Atomic Difference recall answers what changed, magnitude-claim fidelity answers how much, region overlap answers where, and Cause Envelope recall answers why. The deterministic evidence adapter remains a protocol/scoring fixture, not evidence that an external language model has passed the benchmark.

## Design constraints
- Do not change the Structured Report schema, module version, report bytes, or Impact policy.
- Score exact report magnitude fields with their availability status, JSON value, and unit.
- Preserve multidimensional measurements; do not introduce a combined visual-difference score.
- Associate claims only with the Atomic Difference IDs cited by the same answer item.
- Missing claims reduce recall; altered or fabricated field/status/value/unit tuples count as invalid magnitude claims.
- Keep the report-only task boundary explicit and do not claim operating-system sandboxing for arbitrary adapters.
- Extend the existing metrics and threshold contracts additively, following the repository's established version-1 compatibility practice.

## Acceptance Criteria
- [x] The scorer measures per-case and aggregate magnitude-claim recall.
- [x] The scorer counts magnitude claims that do not match canonical evidence for their cited Atomic Differences.
- [x] The strict benchmark requires full magnitude recall and zero invalid magnitude claims.

- [x] Failure attribution classifies magnitude threshold failures as Agent interpretation failures.
