## Description
Replace isolated scalar fields with a multidimensional Difference Magnitude and deterministic, versioned Domain Ordering suitable for agent prioritization.

## Design
Preserve exact parameter delta, symmetric relative delta, CSS displacement, viewport fraction, coverage/raster counts, and channel RMSE where available. Produce an explicit lexicographic ordering tuple per domain rather than a universal score. Missing measurements remain `not_computed`, never numeric zero.

## Acceptance Criteria
- [x] `1.0` to `0.99999` retains exact continuous geometry evidence independent of raster response.
- [x] Paint and presence differences expose domain-appropriate numeric dimensions.
- [x] Same-domain differences are returned in stable descending Domain Ordering.
- [x] Ordering policy ID and tuple components are serialized.
- [x] Targeted tests and native checks pass.

## Close Notes
Added optional multidimensional parameter, geometry, presence, and raster magnitude fields; canonical RGBA8 RMSE; and versioned domain-specific lexicographic tuples. Same-domain differences sort descending while first-seen domain order is preserved. Verified with exact tiny-delta, paint/presence, and ordering tests plus the full 49-test native suite.

Review follow-up: generic insertion and deletion differences now derive affected entity count and source bounds from their Subject Alignment, plus painted area from their event-local raster response. Added circle insertion/deletion regressions covering both directions and verified all 59 native tests.

Second review follow-up: painted coverage now samples nontransparent pixels from the presence side inside the aligned subject bounds, independently from final changed-pixel evidence. An opaque duplicate insertion therefore reports 16 CSS px² painted coverage and zero raster difference instead of collapsing both to zero. Verified all 63 native tests.
