## Description
Audit the M1 milestone gate requiring the report schema, exit codes, profile identity, and compact Agent JSON to have explicit compatible identities and executable dispatch rules.

## Design
Do not invent one global version or a second compact-report schema. Require each semantic domain to name its owning identity: module SemVer for CLI syntax and exit statuses, `schema_version` for the Structured Report, renderer conformance profile ID for accepted rendering claims, and the same Structured Report identity for compact JSON because compact mode changes whitespace only. Require version output, compatibility cases, and parsed compact/default identity tests to agree.

## Acceptance Criteria
- [x] The CLI/module version owns syntax, stream behavior, and exit-status compatibility.
- [x] Every accepted Structured Report schema is registered with migration decisions.
- [x] Renderer conformance is independently identified in the Comparison Profile and version output.
- [x] Compact Agent JSON is byte-smaller but parses to the same Schema document as canonical JSON.
- [x] Unknown report and ordering identities are rejected before semantic interpretation.
- [x] Executable version output agrees with module, Schema, conformance, and ordering authorities.
