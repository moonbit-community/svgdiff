## Description
Prove for the currently supported mutation surface that causal containment is invariant under comparison direction and therefore covers both occupied and vacated before/after outcomes.

## Design
Generate one production report in each direction for every mutation pair. Reverse the independently declared before and after values when locating the actual Changed Fact. Apply the complete Cause Envelope containment property to both reports and forbid sound guarantees on partial reports in either direction. Keep future transform, filter, mask, and compositing propagation unchecked in their existing roadmap items.

- [x] Every complete region in both directions contains the direction-correct actual fact.
- [x] Partial cases revoke the sound guarantee in both directions.
- [x] The test reports direction-expanded complete-comparison and region counts.
