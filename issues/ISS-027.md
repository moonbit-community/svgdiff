## Description
Add manually authored reference labels for the curated corpus's main visual-semantic changes, their relative importance, and acceptable alternative descriptions.

## Design
Keep labels in a versioned annotation file separate from SVG inputs and the engine smoke expectations. Give every curated case at least one reference change, a within-case rank, an ordinal human tier with rationale, and multiple acceptable phrasings. Treat equivalent spelling and zero-contribution insertion as real semantic edits with `none` visual importance rather than erasing them.

## Acceptance Criteria
- [x] Every curated corpus case has exactly one annotation record.
- [x] Every record identifies at least one main visual-semantic change and a within-case rank.
- [x] Human importance tiers include a rationale and do not replace report measurements.
- [x] Every change has multiple acceptable alternative descriptions.
- [x] An automated check rejects missing, duplicate, or structurally invalid annotations.
