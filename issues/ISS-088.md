## Description
Phase 3 begins with a renderer-independent path-data model. The current engine treats every `<path>` as an unsupported visual subject and delegates parsing only to a renderer that can stop at malformed input without reporting a complete parse. Later geometry comparison cannot preserve exact authored evidence or distinguish equivalent relative, shorthand, and compact syntax without a strict source adapter.

## Design
Add a package-private path module that implements the complete deterministic static SVG path command grammar, rejects trailing or partially parsed invalid data, and records half-open UTF-16 spans into the original SVG source. Normalize relative coordinates, horizontal and vertical lines, repeated moveto groups, and smooth control-point shorthand into an absolute semantic segment IR while preserving the authored slice and command provenance for each segment. Attach the parsed segment inventory to path `SourceSubject` records, but retain the existing `unsupported_visual_subject` guard: path correspondence, geometric comparison, painted-boundary measurements, transforms, stroke geometry, and complete computed/rendered coverage belong to later roadmap items.

## Acceptance Criteria
- [x] All SVG path commands, repeated parameter groups, compact separators, signs, decimals, exponents, arc flags, multiple subpaths, and close-path state are parsed strictly.
- [x] Relative, horizontal/vertical, and smooth shorthand commands normalize into deterministic absolute semantic segments with correct reflected controls.
- [x] Every normalized segment retains its exact authored slice and a half-open UTF-16 Source Span into the original SVG input.
- [x] Empty path data is represented explicitly, while malformed, incomplete, non-finite, or trailing path data is rejected rather than accepted as a valid prefix.
- [x] Path subjects retain normalized segment evidence without claiming computed or rendered support and existing unsupported-path comparisons remain conservatively partial.
- [x] Current-contract documentation identifies the new source-only boundary and its deferred geometry-comparison work.
- [x] Relevant MoonBit and repository validation gates pass.
