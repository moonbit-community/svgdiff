## Description
Run the repository's required deterministic validation gates on every push and pull request.

## Design
Add one least-privilege Ubuntu workflow using the same MoonBit installation path already documented by the repository's Copilot setup workflow. Keep each checklist concern visible as a separate step: generated interfaces and formatting, warning-clean native checks, MoonBit tests, CLI integration, Schema and compatibility validation, fixed-seed fuzz smoke, and benchmark sanity. Generated-interface and formatting commands must be followed by a clean-worktree assertion so CI detects stale checked-in output.

## Acceptance Criteria
- [x] The workflow runs on pushes, pull requests, and manual dispatch.
- [x] `moon info` and `moon fmt` fail when they change checked-in files.
- [x] Native warning checks and MoonBit tests run explicitly.
- [x] CLI integration and version identity run explicitly.
- [x] Schema examples and compatibility validation run explicitly.
- [x] Fixed-seed fuzz smoke and benchmark sanity run explicitly.
- [x] Workflow permissions and timeout are bounded.

## Close Notes
Added a least-privilege Ubuntu CI workflow for pushes, pull requests, and manual dispatch with concurrency cancellation and a 20-minute job timeout. The workflow uses the same MoonBit installer already established by the repository's Copilot setup workflow.

Separate visible steps run `moon info` and `moon fmt` followed by `git diff --exit-code`, warning-clean native checks, all MoonBit tests, CLI integration, version identities, canonical Schema regeneration, compatibility decisions, fixed-seed production fuzzing, and the deterministic benchmark pass/fail sanity gate.

Validated the workflow as YAML and ran every workflow command locally. All 105 MoonBit tests, CLI/version gates, seven canonical reports, five accepted and two rejected compatibility cases, two byte-identical fuzz manifests with replay, and benchmark positive and negative controls passed. `git diff --check` remained clean.
