## Question

Which event facts belong in the always-visible summary, which Atomic Difference facts appear one level below, and which evidence belongs behind progressive disclosure so a reviewer can answer what changed, how much, where, and why without losing the complete inventory?

## Notes

- 2026-07-18: Accepted five question-driven Review Information Layers: Report Overview, Event Scan Summary, Atomic Difference Inventory, Evidence Drill-down, and Raw Report. Visual Events are the primary reading unit; overview and lower layers link rather than duplicate authoritative detail.
- 2026-07-18: Accepted an always-visible three-row Event Scan Summary: subject/Event identity plus classifications; Event Canvas Response plus exact Impact relation; then Atomic Difference relation counts, highest localization surface and region count, evidence limitation, and Diagnostic count. Detailed child, magnitude, causal, method, provenance, and coordinate evidence stays below.
- 2026-07-18: Accepted a complete default-visible Atomic Difference Inventory inside every Event. Each compact child row shows exact domain, source values, Computed Relation and reason, evidence layers, one direct magnitude value or availability state, and Shared Event Localization status. No Impact filtering, `+N more`, arbitrary threshold, or cross-domain magnitude ordering may hide or rank children.
- 2026-07-18: Accepted Evidence Ownership and removed nested duplication. Event Measurements, Localization, and Possible Causes & Limitations render once per Event; child Source & Computed, Magnitude, and Provenance & Ordering render per Atomic Difference and link to their owning Event. Changed Facts and Diagnostics have canonical detail locations with references elsewhere.
- 2026-07-18: Accepted a Compact Report Overview with analysis status, counts, Schema/Profile identity, a small uncalibrated Impact Map, and Rendered Outcome Group navigation. Full frontier groups, witnesses, coverage, Event/Atomic IDs, Diagnostics, and policy details remain at their owning layers.
- 2026-07-18: Accepted a deterministic Default Disclosure State: overview, outcome groups, Event summaries, and complete child inventories start visible; owned evidence sections, global Diagnostic detail, and Raw Report start collapsed. Every limitation remains visible in summaries and links to its canonical detail; empty sections do not create meaningless controls.

## Close Notes

Resolved the HTML information architecture as five question-driven layers rather than Schema order. The Compact Report Overview provides only global status and navigation. Every Event has a three-row scan summary and a complete default-visible Atomic Difference inventory. Event and child evidence follow strict ownership, eliminating repeated Event trees, Changed Facts, Diagnostics, regions, and magnitudes. Detailed measurements, localization, causes, limitations, provenance, methods, and raw values use deterministic progressive disclosure while all warnings remain visible outside collapsed sections. Complete JSON remains the final searchable, copyable, downloadable evidence layer rather than a substitute for organized presentation.
