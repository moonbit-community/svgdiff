## Description
Add reproducible alternate-scale rerendering that exposes renderer quantization and directional behavior without changing canonical Structured Report evidence.

## Design
Render a focused pair manifest through the evaluation-only pinned-renderer adapter at output scales 1, 2, 4, and 8. Record premultiplied-RGBA8 comparison curves and directional asymmetry in a separate versioned QA artifact. Compare it with a committed deterministic baseline and assert that canonical CLI reports contain no alternate-scale fields.

## Acceptance Criteria
- [x] A versioned manifest covers exact equivalence, positive and negative micro-movement, and a salient paint change.
- [x] The QA report records deterministic per-scale dimensions and premultiplied-RGBA8 metrics.
- [x] Directional micro-movement behavior is reported rather than collapsed into one score.
- [x] Exact-equivalent inputs must remain exact at every scale.
- [x] A committed baseline makes renderer QA drift observable.
- [x] The QA artifact explicitly denies canonical report-evidence status.
- [x] Integration tests prove canonical Structured Reports contain no alternate-scale output.

## Close Notes
Added the versioned alternate-scale manifest, positive micro-movement fixtures, deterministic QA runner, committed baseline, and shell integration test. The baseline covers four pairs at scales 1, 2, 4, and 8, preserves separate premultiplied-RGBA8 metrics, and reports all four positive-versus-negative micro-movement comparisons as asymmetric under the pinned renderer.

The artifact records `canonical_report_evidence: false`, and the integration test verifies that canonical schema `1.0` reports contain no alternate-scale fields. This observational QA addition does not change accepted renderer dispositions, guards, tolerances, or capability claims, so the existing conformance profile remains `svgdiff-renderer-conformance-profile/1`.

Verified generated interfaces and formatting, warning-clean native checks, all 94 MoonBit tests, CLI integration, exact QA-baseline reproduction, Python syntax, local Markdown links, and `git diff --check`.
