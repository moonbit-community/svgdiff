## Description
Publish `Milky2018/svgdiff@0.3.3` as a focused, consumable native MoonBit library module.

## Design
Treat registry packaging as a separate boundary from the repository workspace and native CLI release. Provide a concise Mooncakes-facing README, nonempty description and keywords, and exclude the CLI, tests, trackers, research, evaluation corpora, prototypes, scripts, release automation, and other maintainer-only artifacts. Keep only the root and `engine` production packages, their generated interfaces, the registry README, manifest, and license.

Validate the exact `moon package --list` inventory, run `moon publish --dry-run` so the toolchain extracts and checks the produced zip, and compile a separate temporary consumer module against that extracted package through a workspace dependency. Publish only if the registry manifest endpoint still reports the module absent and the local Mooncakes credentials accept the operation. Do not fabricate a source repository URL while this checkout has no configured Git remote.
