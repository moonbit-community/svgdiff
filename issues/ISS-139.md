## Description
The Phase 7 roadmap requires stable links from summary events to Atomic Differences, Changed Facts, regions, Cause Envelopes, and Diagnostics. The existing report-local reference gate rejects dangling or duplicate IDs and validates every downstream reference, but it does not reject a frontier group that names a valid Atomic Difference belonging to another event.

Enforce the semantic edge from each Impact frontier group to the exact ordered union of Atomic Differences owned by its listed Visual Events. Keep downstream evidence reachable transitively through the existing event, difference, region, Cause Envelope, Changed Fact, and Diagnostic links rather than duplicating all IDs in Impact Assessment.

## Design constraints
- `ImpactFrontierGroup.event_ids` remains the summary event selection.
- `ImpactFrontierGroup.atomic_difference_ids` must exactly equal the stable de-duplicated report-order union contributed by those events.
- Every Atomic Difference continues to belong to exactly one Visual Event.
- Changed Facts and computed Diagnostics remain reachable through Atomic Differences.
- Difference Regions, Cause Envelopes, candidate Changed Facts, and causal Diagnostics remain reachable through Visual Events.
- Do not duplicate regions, causes, facts, or Diagnostics inside Impact Assessment.
- Do not change Schema `1.43`, module version, report bytes, or policy identity.

## Acceptance Criteria
- [x] The determinism validator rejects a valid-but-wrong frontier Atomic Difference link.
- [x] The validator enforces exact ordered event-to-difference projection for every frontier group.
- [x] Existing direct reference closure and downstream event/difference/region/cause links remain enforced.
- [x] Current documentation defines summary traceability as a transitive evidence graph rather than duplicated summary payload.
- [x] The exact Phase 7 roadmap item is checked.
- [x] Focused and full relevant gates pass without a report-contract change.
