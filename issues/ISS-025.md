## Description
Create a versioned corpus of real SVG document pairs covering the baseline evaluation categories required by roadmap Phase 0.

## Design
Store immutable hand-authored SVG pairs under `evaluation/corpus/cases`, describe them in a machine-readable manifest, and validate that every required category is present, every referenced file exists, and every pair produces its declared analysis status and minimum report shape through the real CLI. Keep mutation generation and semantic, region, cause, importance, and natural-language ground truth out of this item.

## Acceptance Criteria
- [x] The corpus includes equivalent, subtle, salient, structural, resource-mediated, zero-contribution, and unsupported cases.
- [x] Every case is a pair of standalone SVG files with an explicit comparison viewport.
- [x] A versioned manifest provides stable case IDs, categories, paths, and minimal engine expectations.
- [x] An automated check validates manifest integrity and runs every pair through `cmd/svgdiff`.
- [x] Corpus boundaries and later annotation responsibilities are documented.
