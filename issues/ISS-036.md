## Description
Document stdin/stdout behavior, decide whether `-` denotes an SVG stream, and make the CLI preserve machine-readable stdout on both success and error paths.

## Design
Accept `-` for exactly one input and read that complete SVG from stdin. Reject two `-` inputs because one finite stream cannot unambiguously encode two documents. Emit canonical JSON on stdout only when `--output` is absent; send argument and I/O errors to stderr. Keep help and version on stdout. Record the decision in an ADR and current CLI contract.

## Acceptance Criteria
- [x] Either the before or after SVG may be read from one explicit `-` stdin operand.
- [x] Two `-` operands are rejected before reading stdin.
- [x] Default JSON output and informational output use stdout; argument and I/O errors use stderr.
- [x] `--output` leaves stdout empty while still permitting independent `--html` output.
- [x] Unit and installed-binary integration tests cover both stdin positions, double-stdin rejection, and stream separation.
