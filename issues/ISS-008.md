## Description
Give agents spatial evidence for where each visual event differs instead of only reporting a canvas-wide changed-pixel count.

## Design
Derive connected Difference Regions from the canonical pixel mismatch mask when rendered evidence is available. Record integer pixel bounds, CSS bounds, changed-pixel count, and viewport fraction. For source-only partial analysis, use the conservative union of before and after subject bounds and mark the region source as computed bounds.

## Acceptance Criteria
- [ ] Local changes produce stable region bounds in JSON.
- [ ] Spatially disconnected changes produce separate regions.
- [ ] Source-only analysis preserves conservative subject bounds when pixels are unavailable.
- [ ] Region counts do not double-count pixels within one event.
- [ ] Targeted tests and native checks pass.
