## Description
Build a visual-subject inventory for the supported basic-shape subset and align subjects set-to-set. Authored IDs and source order may be evidence but must not define identity.

## Design
Extract normalized subject signatures from visual role, element kind, resolved basic geometry, paint, and hierarchy. Use deterministic exact-signature matching first, then deterministic minimum-cost matching within compatible kinds. Represent one-to-one, insertion, deletion, split, and merge membership as set-to-set alignments. Keep resources separate from placed entities.

## Acceptance Criteria
- [ ] Reordering and ID renaming of equivalent shapes produces no visual differences.
- [ ] Insertions and deletions produce alignments with an empty side.
- [ ] Multiple similar shapes align deterministically.
- [ ] Alignment records are serialized in the structured report.
- [ ] Targeted tests and native checks pass.
