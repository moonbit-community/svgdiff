## Description
Turn the existing deterministic behavior for equally plausible Subject Alignments into an explicit policy with regression coverage.

## Design
Document and retain the current v1 behavior. Exact visual-signature duplicates pair in before source order with the first unused after subject in source order. Minimum-cost candidates first sort by visual signature using MoonBit shortlex order and then source index; the assignment algorithm keeps the first stable candidate when reduced costs tie. Authored IDs do not break visual ties. Clarify that deterministic selection is not a confidence or uniqueness claim.
