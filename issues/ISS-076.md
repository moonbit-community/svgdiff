## Description
Turn the existing self-contained HTML report isolation design into a dedicated security gate for hostile SVG source.

## Design
Keep the production renderer unchanged unless the gate finds a defect. Generate a report from fixed hostile SVG fixtures, validate the outer document structure and escaped embedded report, then load the artifact in the project's pinned offline Chromium environment. The browser check must prove that both previews retain an empty `sandbox`, their fixed `default-src 'none'` policies are present, hostile scripts do not mutate the parent or preview documents, and hostile external resources do not produce requests.

## Acceptance Criteria
- [x] Both preview documents retain an empty iframe sandbox and fixed restrictive CSP.
- [x] Hostile quote and element-boundary text cannot escape `srcdoc` or the report JSON textarea.
- [x] Inline SVG scripts and event handlers do not execute in either preview.
- [x] External SVG resources do not produce browser requests.
- [x] The generated HTML remains bound to the exact Structured Report JSON.
- [x] The dedicated gate is documented and included in the project validation commands.

## Close Notes
Added fixed hostile SVG fixtures that combine outer-element boundary text, quotes, ampersands, inline scripts, event handlers, stylesheet imports, and external image references. A structural validator now requires the exact top-level and preview CSPs, exactly two empty-sandbox `srcdoc` previews, one fixed outer script, escaped hostile boundaries, and a byte-equivalent JSON value after textarea decoding.

The dedicated browser gate loads the generated artifact in pinned `@playwright/cli@0.1.17` Chromium with networking disabled. It confirms that both SVG preview DOMs load while their scripts and event handlers remain inert, neither preview mutates the parent report, no request is emitted for the hostile external resource origin, and the fixed report presentation script still parses the exact embedded report.

Documented the boundary and validation command without claiming resource-budget protection. Verified the static validator, pinned Chromium gate, native warning check, all MoonBit tests, CLI and fuzz integration, local Markdown links, and `git diff --check`.
