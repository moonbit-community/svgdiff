## Description
Complete the operation-transfer half of the accepted Influence Provenance model. Supported analyzers already enumerate conservative operation participants: group surfaces name their container and descendants; clip, mask, and filter facts name every consumer; blend and isolation facts name the foreground plus the ordered backdrop prefix inside the isolation boundary; stacking facts name each inverted pair. Cause Envelope attachment must union these operation participants with entity-alignment identities before querying the subject token index.

Replace the temporary rule that widens every complete group-opacity, blend, isolation, or stacking event to the full comparison fact universe. Complete supported operations may use their conservative participant set plus every event sharing the same Difference Region. Partial reports, empty candidate sets, and any unsupported operation continue to use the established comparison fallback or revoke completeness.

## Design constraints
- Use one private typed operation classifier for group surfaces, clips, masks, filters, blending, isolation/source-over, and stacking/compositing order.
- Leaf entity events keep alignment-only subject pruning; operation events union alignment identities with direct-fact `affected_subject_ids`.
- Group-opacity surfaces must retain container and descendant input tokens; a simultaneous changed backdrop is retained through the event that shares the same pixel-region identity.
- Clip, mask, and filter operations must retain both content/host input tokens and resource/operation parameter tokens for every conservative consumer.
- Blend and isolation operations must retain foreground, isolation boundary, and complete ordered backdrop-prefix tokens.
- Stacking regions must retain the inverted-pair tokens and any concurrent event tokens sharing that exact region, without contaminating a disjoint region.
- Complete operation transfer may over-report participants but must not drop an actual changed cause.
- Partial coverage and empty-candidate fallback remain comparison-wide with `not_established` where required.
- Do not claim tile-level attribution, exact contribution, minimal causes, visibility, or severity.
