## Description
Validate the second terminal acceptance claim: every applicable reported magnitude preserves its named exact, geometric, raster, painted-coverage, color, and perceptual evidence rather than collapsing dimensions into a visibility boolean, universal scalar, severity label, or cross-domain order.

## Design constraints
- Keep authored/computed parameter deltas independent from renderer-quantized geometry and pixels.
- Preserve local-user-unit, CSS-pixel, viewport-relative, entity-relative, transform-effect, painted-boundary, alpha-coverage, presence, scene-raster, intrinsic-raster, DeltaEOK, and LDR-FLIP fields with their own units and denominators.
- Treat unavailable values as null or explicit `not_computed`; never serialize missing evidence as measured zero.
- Keep raw magnitude fields authoritative over derived Domain Ordering and Impact Assessment.
- Validate representative production reports and canonical examples for every magnitude family, plus report-only Agent fidelity for exact magnitude claims.
- Do not add new magnitude semantics, calibrate Impact, create severity classes, or change product code, public APIs, Structured Report Schema, profiles, policies, fixtures, dependencies, CI, or release assets unless a separate defect is verified.

## Acceptance Criteria
- [x] A versioned terminal gate manifest inventories every current magnitude family, its fields, units/denominators, availability rule, authorities, and focused tests.
- [x] Machine validation rejects missing families, fields, units, availability rules, authorities, tests, or anti-collapse rules.
- [x] A tiny `1.0` to `0.99999` geometry probe preserves exact parameter scales separately from boundary, coverage, and raster observations.
- [x] A salient paint probe preserves scene raster, alpha-only coverage, event-local DeltaEOK, and opt-in LDR-FLIP map/statistics under explicit profile inputs.
- [x] Canonical insertion, transform, and embedded-raster examples preserve presence, tagged transform-effect, and intrinsic-raster evidence.
- [x] Unsupported text or unavailable evidence remains absent/not-computed rather than measured zero.
- [x] Focused magnitude, geometry, raster, perceptual, ordering, Impact, schema-example, mutation, evaluation-metric, and retained language-model observation checks pass.
- [x] Current magnitude, Impact, Agent, profile, roadmap, and documentation-index texts describe the terminal claim without inventing a universal score.

- [x] `moon info`, `moon fmt`, strict native check, full native tests, tracker generation, and `git diff --check` pass.
