## Question

Which concrete scenarios, task timings, evidence-preservation checks, interaction checks, accessibility requirements, and hostile-source constraints must an implementation satisfy before the redesign can be considered complete?

## Acceptance Criteria

- [x] Visual Events are the default browsing unit and appear in measured-nonzero, not-computed, then measured-zero Rendered Outcome Groups without collapsing relation, domain, or availability facts.
- [x] Every owning Atomic Difference remains visible by default inside its Event and exposes exact domain, source values, Computed Relation, evidence layers, one direct magnitude/availability value, and Shared Event Localization.
- [x] Event summaries expose identity, Canvas Response/Impact, child relation counts, localization status, limitations, and Diagnostic counts without inventing calibrated severity or total ordering.
- [x] Event-owned and Atomic-owned evidence have one canonical detail location; complete Structured Report JSON remains searchable and copyable behind a collapsed disclosure.
- [x] Hover/focus temporarily previews the Event-owned localization; activation persists one Event selection; review marks, filtering, disclosure, and viewport navigation remain independent.
- [x] Atomic review marks drive tri-state Event and outcome-group controls over all descendants, including filtered descendants, and reset on reload.
- [x] Event and Atomic filters only change visibility, report visible/total counts, and suspend rather than destroy a hidden localization selection.
- [x] Both sandboxed SVG previews remain synchronized, use explicit fit/reset controls, and never auto-zoom on hover or selection.
- [x] Legacy Schema 1.44 localization degrades explicitly to observed bounds, conservative bounds, or unlocalized text; HTML does not rerender or infer missing evidence.
- [x] Hostile SVG scripts, event handlers, and network requests remain isolated; keyboard operation, accessible labels, partial/failed reports, empty reports, tied/incomparable Impact, and complete child preservation have browser checks.
