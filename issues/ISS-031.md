## Description
Compute Atomic Difference recall, main-difference ranking quality, region overlap, Cause Envelope recall, and conservative false-positive volume from report-only agent answers and hidden curated-corpus labels.

## Design
Score report production and agent interpretation separately where possible. Use the report's Atomic Difference IDs as the immediate agent-recall target, hidden ranking targets for reciprocal rank, exact-bound IoU or conservative-bound containment for localization, and semantic actual-cause locators for report and agent causal recall. Preserve per-case results and macro aggregates; do not collapse them into one universal score or define release thresholds in this item.

## Acceptance Criteria
- [x] Metrics include agent Atomic Difference recall and main-difference reciprocal rank.
- [x] Region scoring distinguishes report regions from agent-selected regions and exact IoU from conservative containment.
- [x] Cause scoring distinguishes report Cause Envelope recall from agent-retained possible-cause recall.
- [x] False-positive cause volume and invalid evidence references remain visible.
- [x] A report-only evidence adapter attains the expected baseline, while an empty-answer adapter demonstrably scores lower.
