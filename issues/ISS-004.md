## Description
Turn the validated structured-report prototype into a usable SVG diff engine. The epic covers conservative coverage reporting, subject alignment, complete fact enumeration for the supported static subset, spatial localization, causally complete over-approximation, domain-specific magnitudes and ordering, a stable JSON contract, CLI delivery, and the previously accepted self-contained HTML report.

## Design
Implement vertical slices through the public `compare(before_svg, after_svg, comparison_profile) -> structured_report` seam. Preserve source, computed, and rendered evidence separately. Never claim equality for unsupported content. Explicit v1 non-goals and deferred font work remain recorded rather than simulated.
