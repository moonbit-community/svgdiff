# ISS-101: Preserve declaration provenance through cascade resolution

## Description
Every supported cascade winner must retain the exact declaration origin and half-open UTF-16 Source Span from the original SVG input. Cascade, inheritance, CSS-wide defaulting, custom-property substitution, `currentColor`, shorthand expansion, and renderer normalization may compute effective values, but must not rewrite declaration provenance or manufacture a new declaration origin.

## Design
Treat `DeclaredVisualFact` as immutable source evidence. Cascade selection returns the winning fact unchanged. Resolution metadata expresses local, inherited, initial, or computed behavior through `ResolvedVisualFact.resolution`, `declaration_owner_id`, and `inheritance_depth`; it does not encode those states by changing `DeclaredVisualFact.origin`. Derived marker longhands may change the effective property name while retaining the shorthand declaration's authored value, declared value, origin, and Source Span. Renderer materialization remains private and never becomes report provenance.

## Acceptance Criteria
- [x] Presentation-attribute, inline-style, and matched-stylesheet winners retain their exact authored value, normalized declared value, origin, and Source Span after cascade selection.
- [x] Duplicate declarations, `!important`, selector specificity, and source-order resolution return the winning declaration provenance rather than the last parsed or materialized value.
- [x] Ordinary inheritance, CSS-wide defaulting, custom-property substitution, and `currentColor` retain the original declaration provenance while reporting resolution mode, owner, and depth separately.
- [x] Marker inheritance and shorthand expansion do not synthesize `inherited_*` declaration origins.
- [x] Report-level and JSON regressions prove that every admitted winning declaration span slices the original input to its exact authored value.
- [x] A declaration move between origins remains a Source Semantics difference even when computed and rendered results are equivalent; offset-only formatting movement does not become a visual difference.
- [x] Core model, feature coverage, and an ADR state the immutable-provenance boundary and remaining excluded CSS origins.
- [x] Relevant MoonBit and repository validation gates pass.
