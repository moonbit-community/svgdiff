## Description
Replace the fixture-specific `fill` and `x` source lookups in the Structured Report prototype with a small declared-visual-fact model for one solid-painted SVG `rect`. The slice must preserve authored provenance while distinguishing formatting-only variation, declared differences, computed appearance, and rendered evidence in the JSON report.

## Design
Extract the first supported `rect` into declared facts for `x`, `y`, `width`, `height`, `fill`, and `opacity`. Each fact records its property, authored value, normalized declared value, declaration origin, and source span. Presentation attributes and inline `style` declarations feed the same fact model, with inline style taking precedence for the same property. Compare all extracted facts, then relate them to the existing normalized scene and event-level raster observation.

This slice deliberately keeps the existing single-rect subject assumption. It does not implement inheritance, stylesheets, selectors, multiple-element alignment, transforms, gradients, fonts, general CSS parsing, or the final production schema. Unsupported CSS that could affect the rect must reduce analysis coverage through a Diagnostic rather than be treated as equality.

## Acceptance Criteria
- [x] `x`, `y`, `width`, `height`, `fill`, and `opacity` are extracted through one declared-fact abstraction with authored value, normalized declared value, origin, and source span.
- [x] Presentation attributes and inline `style` declarations converge into the same property model, with inline style precedence represented explicitly.
- [x] Attribute order, quote style, tag-closing style, and declaration whitespace alone produce no Atomic Difference.
- [x] `fill="red"` to `fill="#ff0000"` produces a Source Semantics difference with equivalent computed paint and zero rendered magnitude.
- [x] Moving `fill="red"` to `style="fill:red"` produces a declaration-provenance difference while retaining equivalent computed paint.
- [x] `x="1.0"` to `x="0.99999"` retains the numeric computed delta and rendered observation.
- [x] A visibly different fill retains source, computed, and rendered evidence.
- [x] Unsupported CSS affecting the rect produces an explicit Diagnostic and partial analysis instead of an equality result.
- [x] The JSON report preserves declared-fact provenance, and existing prototype scenarios continue to pass.
- [x] `moon info`, formatting checks, `moon check --target native --warn-list +73`, and `moon test --target native` pass apart from documented pre-existing warnings.
