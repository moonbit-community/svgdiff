## Description
Make identical SVG inputs and Comparison Profiles produce byte-deterministic Structured Reports whose report-local identifiers are unique and whose declared references always resolve.

## Design
Run a versioned fixture matrix through separate release-CLI processes in both default and compact modes. Require byte identity within each mode and semantic identity across modes. Validate one global namespace for Subject Alignment, Changed Fact, Atomic Difference, Visual Event, Difference Region, and Diagnostic IDs, plus closure for every field that is defined as a report-local reference. Keep source-subject identities explicitly outside this foreign-key contract because schema `1.0` has no canonical subject table.

## Acceptance Criteria
- [x] A versioned matrix covers equivalent, changed, inserted, deleted, resource-mediated, unsupported, multi-event, and non-default-viewport reports.
- [x] Repeated independent CLI processes emit byte-identical default JSON and byte-identical compact JSON for identical inputs and profiles.
- [x] Default and compact output decode to the same report evidence.
- [x] Every report-local object ID is nonempty and globally unique within its report.
- [x] Every declared report-local reference resolves to exactly one object of the required kind and contains no duplicate targets.
- [x] Every Atomic Difference belongs to exactly one Visual Event.
- [x] Negative controls prove that duplicate IDs and dangling or duplicate references are rejected.
- [x] Current documentation defines the determinism and source-subject identity boundary.
