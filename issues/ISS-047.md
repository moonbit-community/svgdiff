## Description
Define the minimum evidence required to keep a renderer gap as a conservative guard, propose a focused upstream patch, or create a project-owned MoonBit rendering module.

## Design
Use conformance cases rather than a global pass percentage. One minimized reproducible failure is sufficient for a focused upstream patch. A project-owned layer requires an active-milestone blocker, at least three independent cases through either a breadth or project-specific-control trigger, evidence that a released upstream solution is not viable, and an explicit smallest-layer maintenance plan. Every complete-eligible case must still have zero unexplained divergence.

## Acceptance Criteria
- [x] The policy defines the correctness floor independently from ownership decisions.
- [x] Focused upstream patch and project-owned module thresholds are observable and distinct.
- [x] The policy rejects global pass percentage and pixel magnitude as ownership shortcuts.
- [x] Ownership remains limited to the smallest failing renderer layer.
- [x] The scorecard applies the threshold to every current renderer blocker.
- [x] Current renderer and upgrade documentation link to the decision.
