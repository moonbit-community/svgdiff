## Description
Improve the self-contained HTML report now that the report-only Agent evaluation has identified concrete inspection needs: what changed, how much, where, and why. The current report localizes hovered differences but exposes only domain, source values, and the ordering-policy ID in each item.

Retain the side-by-side sandboxed SVG previews and complete JSON payload, while making Impact status, evidence-layer outcome, raw magnitudes, linked Visual Events, Difference Regions, possible Changed Fact causes, and Diagnostics directly inspectable. The HTML remains derived presentation over the supplied Structured Report and must not create a second semantic model.

## Design constraints
- Do not recompute comparison, ordering, importance, localization, or causality in the browser.
- Present the exact `ImpactAssessment` relation, calibration status, frontier groups, and raw measurements without severity labels or a total order.
- Keep every Atomic Difference visible and grouped by its full domain family; frontier membership may annotate but never filter the inventory.
- For each difference show source before/after values, computed relation, evidence layers, non-null raw magnitude fields, linked event IDs, region IDs/bounds, Changed Fact IDs, and Diagnostic IDs.
- Resolve Changed Fact and Diagnostic IDs to compact inspectable details using only report data.
- Hover, focus, and selection continue to highlight all linked Difference Regions on both previews.
- Preserve checkboxes independently from active-region selection.
- Use DOM construction plus `textContent` for report-controlled values; do not use `innerHTML` or execute embedded source.
- Preserve the empty-sandbox preview, CSP, offline self-containment, complete JSON view, default JSON/CLI behavior, and Structured Report Schema `1.43`.
- Add real-browser validation for content, keyboard focus, selection, region overlays, cause/Diagnostic expansion, and hostile-source isolation.
