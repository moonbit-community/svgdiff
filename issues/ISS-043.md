## Description
Build an independent browser-based rendering oracle for supported deterministic fixtures.

## Design
Keep the oracle outside the production engine. Use pinned Playwright CLI to drive Chromium offline at DPR 1 and an explicit viewport, load SVG through base64 data URLs, capture with a transparent background, and record browser identity plus source and PNG hashes. Validate two complete runs for byte-level reproducibility.

## Acceptance Criteria
- [x] A fixed manifest covers both sides of every complete curated corpus pair.
- [x] Chromium runs offline with explicit viewport, DPR 1, and transparent background.
- [x] Output records browser/CLI identity, dimensions, source hashes, and PNG hashes.
- [x] Validation rejects missing, unsafe, dimensionally wrong, non-RGB/RGBA, or hash-mismatched artifacts.
- [x] Two independent captures produce byte-identical PNGs and reports.
- [x] The oracle remains outside the core engine and canonical report contract.
