## Description
Provide tested Bash, Zsh, and Fish completions plus a deterministic local installer, and record why package-manager formulas are not maintainable before versioned native release artifacts exist.

## Design
Keep completion definitions as static reviewed files whose option set is checked against `svgdiff --help`. Install them into shell-appropriate user locations or an explicit destination. Do not publish Homebrew, Scoop, or other package definitions until a released binary supplies a stable version, URL, checksum, provenance, and supported platform matrix.

## Acceptance Criteria
- [x] Bash, Zsh, and Fish completions cover both SVG operands and every current long option.
- [x] Completion files pass available shell syntax checks.
- [x] Bash behavior completes current options and installs the `svgdiff` completion function.
- [x] One installer supports each shell, explicit destinations, and deterministic reinstall.
- [x] User documentation explains activation and custom destinations.
- [x] Package-manager installation has an explicit maintainability prerequisite instead of an unversioned formula.

## Close Notes
Added maintained Bash, Zsh, and Fish definitions, shell-specific default locations, explicit-destination installation, Zsh activation guidance, and deterministic reinstall tests. The test derives the live option inventory from `svgdiff --help`, checks Bash and available Zsh syntax, executes Bash option and SVG-file completion, and verifies all three default and custom installation layouts. Fish is not installed in the current environment, so its definition receives structural option synchronization here and is syntax-checked automatically wherever Fish is available.

No package-manager formula is published because the preceding native-binary release item remains incomplete. The documented maintainability gate requires a stable release version, URL, checksum, provenance, license bundle, and supported platform matrix; an unversioned source-build formula would not provide a distinct distribution contract.

Verified generated interfaces and formatting, warning-clean native checks, all 97 MoonBit tests, CLI and binary installation integration, completion behavior and installation, local Markdown links, and `git diff --check`.
