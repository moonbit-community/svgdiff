## Description
Investigate whether svgdiff should add within-call memoization, persistent exact-result caching, reusable per-input artifacts, or graph-incremental comparison. Define the correctness, identity, invalidation, trust, resource-limit, and measurement conditions that each shape would require, then accept or defer concrete implementation work without changing current comparison behavior.

This item is an investigation, not authorization to add a cache, change the public API or CLI, expose private intermediate representations, weaken full-inventory recomputation, or treat cached data as evidence without validating every input and semantic identity.

## Design constraints
- Preserve exact deterministic output for the same complete comparison input and implementation identity.
- Include both exact source byte sequences, side-qualified resource inputs, every Comparison Profile value, fixed limits, and every semantic implementation/policy identity in any reusable-result key.
- Keep report Schema identity distinct from engine, renderer, conformance, ordering, Impact, resource, and future execution-profile identities.
- Treat cached bytes as untrusted derived data: verify key, format, integrity, limits, and compatibility before use; a miss or corruption must fall back safely.
- Distinguish within-call memoization, whole-report caching, per-input artifacts, per-stage artifacts, and graph-incremental recomputation rather than calling all of them “the cache.”
- Do not reuse pair-local alignment, event, region, or provenance output after an edit unless dependencies and invalidation are complete.
- Require measured workload benefit before accepting persistent product complexity.
- Do not add product code, dependencies, public APIs, report fields, Schema changes, Diagnostics, CLI flags, fixtures, default CI work, or release assets.

## Close notes

Reserved `svgdiff-exact-result-cache-key/1` as the first future candidate: an optional caller-owned local cache of canonical report bytes keyed by exact ordered source and resource inputs, the complete Comparison Profile, semantic modules/svgdiff/engine/build and dependency identities, every independent policy and adopted execution-profile identity, effective limits and control mode, and target identity where required. Kept full recomputation authoritative, current within-call memoization measured and private, pair-global intermediates non-reusable without a complete dependency DAG, and remote caching rejected until local value plus a trust model are proven.
