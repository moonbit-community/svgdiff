## Description
Record region ground truth or conservative reference bounds for curated corpus cases whose visual outcomes are spatially localizable.

## Design
Use comparison CSS-pixel coordinates tied to each case's declared viewport. Mark simple filled-shape outcomes with exact painted bounds and use conservative bounds when quantization or unsupported stroke geometry makes exact changed-pixel masks inappropriate. Mark equivalent and zero-contribution cases `not_applicable` rather than inventing zero-area regions.

## Acceptance Criteria
- [x] Every curated corpus case declares either localizable reference regions or an explicit not-applicable reason.
- [x] Each localizable region names its coordinate space, reference kind, bounds, and future scoring rule.
- [x] Exact and conservative reference bounds remain distinguishable.
- [x] All bounds are positive and contained within the case viewport.
- [x] An automated check enforces one-to-one corpus coverage and region structure.
