## Question

## Notes

- 2026-07-18: Accepted four exclusive ownership classes at the HTML Projection Seam: Canonical Report Fact, versioned deterministic Lossless Projection, local non-evidence Review State, and Missing Semantic Evidence that must be supplied upstream. Original SVG sources cross only for sandboxed previews; HTML may not recompute comparison evidence.
- 2026-07-18: Kept Rendered Outcome Groups, relation and evidence counts, Domain Families, Magnitude Channels and display formatting, Impact Map coordinates, ownership links, report-local reference resolution, subject labels, counts, grouping, sorting, and disclosure inside a versioned HTML Projection Policy. None requires new core report fields; unknown identities remain raw and explicit.
- 2026-07-18: Required typed side-qualified footprints and exact observed masks to become Canonical Localization Evidence in the self-contained Structured Report. HTML receives no private evidence bundle and never recomputes overlays from SVG sources. Tight mask encoding remains versioned and bounded, with explicit bounds-only or not-serialized fallback states.
- 2026-07-18: Required report-owned Measurement Availability for each canonical measurement family, with computed, not-computed, not-requested, or not-applicable status, reason, Diagnostic references, and optional raw-value reference. UI Magnitude Channels remain projection; legacy null remains `No value reported`.
- 2026-07-18: Defined Event Diagnostic Closure as the deduplicated traversal of explicit references from Event-owned child, measurement, localization, region, cause, and rendered evidence. The count is Lossless Projection; no duplicate Event array or subject/code heuristic is permitted, and producers must attach local limitations to their owning evidence.
- 2026-07-18: Required a new Structured Report Schema identity for new canonical localization and availability facts while preserving Schema `1.44`. New HTML dispatches by schema and uses explicit Projection Compatibility Mode for legacy bounds-only regions, absent side-footprint representation, and unexplained nulls without re-rendering or reinterpretation.
- 2026-07-18: Fixed the Minimal Report Increment to Canonical Localization Evidence, Measurement Availability, and missing Diagnostic references on actual evidence owners. Rendered Outcome Groups, Domain Families, relation/evidence counts, Magnitude Channels and display values, Impact Map, human labels, summaries, review state, styling, and Event Diagnostic counts remain projection or local state.

## Close Notes

Resolved the HTML Projection Seam with four exclusive ownership classes: canonical report fact, versioned lossless projection, local review state, and missing semantic evidence. Existing report fields already support classification, grouping, counts, magnitude formatting, ordering, Impact navigation, reference resolution, and subject labels through a versioned HTML Projection Policy. The only authorized report-interface growth is typed side footprints and encoded observed masks, canonical measurement-family availability, and missing Diagnostic references attached to their true evidence owners. These facts remain inline in one self-contained report, receive a new Schema identity, and degrade explicitly for legacy Schema `1.44` without browser recomputation or null reinterpretation. No UI-ready summaries or duplicate Event Diagnostic arrays enter the core report.
