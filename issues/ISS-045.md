## Description
Prevent every divergence in the renderer-conformance baseline from silently contributing complete rendered evidence.

## Design
Keep exact source and computed evidence. Until a separately versioned conformance tolerance exists, add narrow rendered-evidence Diagnostics for fractional geometry, referenced gradients, and fractional leaf opacity. Retain the existing group-opacity compositing guard. Link every divergent baseline case to its disposition and test that no guarded input remains complete.

## Acceptance Criteria
- [x] Every divergent baseline case has an explicit disposition.
- [x] Fractional geometry cannot produce complete rendered evidence from the quantizing renderer.
- [x] Referenced-gradient raster evidence is guarded without erasing supported source or computed differences.
- [x] Fractional leaf-opacity raster evidence is guarded without treating a 1/255 mismatch as exact.
- [x] Group-opacity divergence remains covered by its stable compositing Diagnostic.
- [x] Exact supported fixtures do not acquire a new renderer-conformance guard.
- [x] The disposition mapping is executable and documented.
