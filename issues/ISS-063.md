## Description
Elevate causal containment from hand-written examples to a deterministic property over every currently supported mutation subject kind and authored property.

## Design
Use the mutation specification's independently declared single Changed Fact as the actual cause for each generated pair. For every complete report and every emitted Difference Region, require `sound_overapproximation` and containment of the uniquely matched declared Changed Fact. For partial reports, forbid `sound_overapproximation`. Add a negative control that removes the actual fact from one complete envelope and prove rejection.

## Acceptance Criteria
- [x] The property runs across the exact six-kind, eighteen-property mutation coverage contract.
- [x] Every complete case uniquely resolves its independently declared actual Changed Fact.
- [x] Every region in every complete case claims `sound_overapproximation` and contains that actual fact.
- [x] Partial mutation cases cannot claim a sound complete Cause Envelope.
- [x] The test is non-vacuous and reports complete-case and region counts.
- [x] A negative control proves removal of one actual cause is rejected.
