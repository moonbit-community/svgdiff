## Description
Replace a report-wide complete/partial label as the only coverage evidence with an explicit matrix of encountered features and Source, Computed, and Rendered coverage cells.

## Design
Add a public `FeatureCoverage` row and additive `coverage_matrix` report field. Discover document, subject, property, emitted domain, and guard rows behind one engine module interface. Use four orthogonal cell states and Diagnostic references, order rows deterministically, and derive `analysis_status` from the strongest cell.

## Acceptance Criteria
- [x] Every current report contains a deterministic feature coverage matrix.
- [x] Each row records Source Semantics, Computed Appearance, and Rendered Evidence independently.
- [x] Limited and failed rows retain the Diagnostics that justify them.
- [x] Top-level analysis status is derived from matrix cells.
- [x] Complete, partial, and failed integration cases exercise the matrix.
- [x] Schema, public MoonBit interface, and agent-facing documentation describe the additive field.
