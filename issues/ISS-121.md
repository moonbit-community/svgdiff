# ISS-121: Add transform-aware rendered-geometry alignment features

- Status: closed

## Description
Make rendered-subject correspondence sensitive to cumulative transforms and device-space geometry so locally identical or similarly authored shapes do not align across different final placements merely because transform declarations were ignored. Preserve deterministic global matching and expose the versioned feature policy without presenting its heuristic score as visual magnitude or calibrated confidence.

## Design
Keep exact use-instance-path matching and current split/merge rules. For direct rendered subjects, replace the transform-blind exact signature with an alignment signature that includes cumulative transform completeness, canonical cumulative matrix, and conservative device-space painted bounds when available. Equivalent source spelling with the same used geometry remains exact; subjects whose local geometry matches but final placement differs proceed to scored matching.

Replace raw property-distance matching with `rendered_geometry_feature_distance_v1`, a bounded dimensionless mean over independently available features: conservative device-space painted-bounds displacement, normalized local appearance-property difference, hierarchy agreement, and normalized path segment/parameter difference. When painted bounds are unavailable on both sides, cumulative-transform probe displacement under the actual Comparison Viewport substitutes for the bounds feature; it is not added when bounds already encode final placement. Geometry properties are represented by device-space bounds instead of being double-counted as raw local coordinates. A one-sided bounds or transform availability mismatch contributes maximal disagreement. The Hungarian assignment continues to minimize the global sum within compatible SVG kinds, and exact equal scores retain the existing deterministic tie-break.

Extend conservative geometry bounds to complete non-arc normalized paths using the control hull of every endpoint and Bezier control point. The hull contains the painted centerline and is safe for alignment/localization; any arc keeps path bounds unavailable rather than receiving guessed extrema. Existing stroke, marker, clip, mask, and cumulative-transform expansion remains authoritative.

Pass the caller's actual Comparison Profile into subject extraction and alignment scoring. Do not render candidate pairs, add a raster similarity oracle, aggregate groups, calibrate confidence, or reuse the alignment score as a Difference Magnitude or Impact Assessment. Source-structural alignments and Visual Resource alignment retain their current separate boundaries.
