## Description
Define versioned regression thresholds for the curated evaluation metrics and publish one reproducible command that generates reports, runs an agent adapter, scores answers, and enforces the thresholds.

## Design
Keep independent minimum and maximum gates rather than a combined score. Include coverage and equality safety, required Diagnostic recall, Atomic Difference recall, ranking, report and agent localization, report and agent causal recall, conservative false-positive counts, and invalid reference count. Default to the deterministic evidence adapter for repository self-verification while allowing an explicit external text-only agent command.

## Acceptance Criteria
- [x] Thresholds are versioned and tied to the metrics and corpus versions.
- [x] Coverage status, equality conclusion, required Diagnostics, and hard safety failures are measurable and gated.
- [x] Every existing core metric has an explicit minimum or maximum threshold.
- [x] One command produces reports, tasks, answers, metrics, and a threshold result in a new output directory.
- [x] Integration coverage proves the evidence adapter passes and an intentionally empty semantic answer fails.
