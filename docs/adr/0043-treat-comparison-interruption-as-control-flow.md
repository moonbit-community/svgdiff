# Treat comparison interruption as control flow rather than analysis evidence

Embedding callers may use a new controlled comparison operation with a caller-owned cancellation predicate and elapsed-time budget. Cancellation and budget expiry raise a typed `ComparisonInterrupted` error and return no Structured Report: an interrupted request has not completed enough work to make `analysis_status`, empty evidence inventories, or Diagnostics semantically valid. Existing `compare` remains unlimited and unchanged. Interruption is cooperative at deterministic engine checkpoints, including measured hot loops; one dependency parse or render call cannot be preempted, so a wall-time budget is detected at the first checkpoint after such a call rather than promised as a hard real-time deadline. The Structured Report Schema, Diagnostic catalog, CLI behavior, and fixed input/output resource limits remain unchanged.
