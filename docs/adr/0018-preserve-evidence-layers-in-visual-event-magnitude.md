# Preserve evidence layers in Visual Event magnitude

A Visual Event will retain its Atomic Differences as source and computed evidence while measuring its final Event Rendered Outcome once over the union of associated Difference Regions. It will not add magnitudes across evidence layers or child differences, and grouping will not turn conservative `may-depend` provenance into exact causal edges; this avoids double-counting one visual outcome while preserving every independently reportable distinction and the existing causal-completeness guarantee.
