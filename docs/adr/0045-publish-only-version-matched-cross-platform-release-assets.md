# Publish only version-matched cross-platform release assets

Native publication is triggered only by a pushed tag exactly equal to `v<moon.mod version>`. The workflow never creates or moves a tag. It builds the same tagged revision on Ubuntu 24.04 x64, Windows Server 2025 x64, and macOS 15 arm64; tests each native candidate; packages the existing checksummed provenance bundle; and captures canonical report bytes from the packaged executable. Publication requires all three archives, byte-identical determinism bundles, and archive-level SHA-256 checksums. `gh release create --verify-tag` publishes the complete asset set only when no release already exists, avoiding silent asset replacement and remaining compatible with immutable GitHub Releases. Signing, notarization, SLSA attestations, and cross-toolchain reproducibility remain separate decisions.
