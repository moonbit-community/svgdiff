# Give each Atomic Difference one Visual Event owner

Every Atomic Difference belongs to exactly one Visual Event, and each current event is anchored to one Primary Subject Alignment; multiple differences for that outcome group in the event and its rendered outcome is measured once over the union of its regions. One Changed Fact may still produce multiple outcomes by being referenced from distinct Atomic Differences in distinct events, so causal fan-out is shared through Changed Fact references rather than by duplicating an Atomic Difference across events; this supersedes ADR-0019's allowance for multi-event Atomic Difference membership. A resource difference may join its sole mediated entity event, but zero-outcome resource changes use a resource event and future multi-outcome resource fan-out must use a separate resource event until a separately versioned contextual-link or cross-subject aggregation policy is accepted.
