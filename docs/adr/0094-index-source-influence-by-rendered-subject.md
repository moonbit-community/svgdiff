# Index source influence by rendered subject

Each Changed Fact already carries analyzer-owned `affected_subject_ids`: a conservative declaration of every rendered subject whose supported computed input may read that fact. Cause Envelope attachment will materialize those edges in one private token index. Entity events query the before/after identities of their entity-role Subject Alignment; insertion and deletion naturally query only the existing side. Resource and relationship events without an entity alignment query the affected subjects of their direct facts. Direct event tokens are always retained, and newly reached tokens append in report order.

This establishes source-input propagation for admitted geometry, paint, resources, transforms, viewport mapping, use instances, and structural relationships without serializing a second graph. It does not claim tile-level attribution or intermediate-surface transfer. Group opacity, clips, masks, filters, blending, isolation, stacking, and source-over compositing keep their current conservative fallbacks until the next Phase 6 transfer item proves narrower rules. Partial reports still widen every available region to the comparison Changed Fact universe and use `not_established`.

The index is a completeness backstop rather than a replacement for Atomic Difference links. A fact directly referenced by an event remains present even if it has no affected subject; a fact indexed only to an unrelated subject remains prunable. This preserves deterministic candidate order and existing canonical reports while ensuring that an analyzer-owned fan-out edge cannot be lost merely because a future event grouping does not duplicate the same Changed Fact link.
